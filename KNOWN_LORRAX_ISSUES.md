# Known LORRAX issues: Sigma/screening/SC thresholds

Registered by the 2026-08-31 threshold audit.  “Silent” means a physically
degenerate request is clipped, defaulted, or cached as a plausible value
instead of being refused.  Line numbers name this branch.

| ID | Status | Locus | Finding |
|---|---|---|---|
| THR-001 | open, high | `src/gw/minimax_screening.py:1110-1111` | The static Laplace lower bound uses the fundamental `cmin-vmax` gap.  A metal has no positive fundamental gap, so the value silently becomes `_TINY=1e-12 Ry`; the resulting range and scaled error request are physically meaningless.  The lower transition scale must come from the actual nonzero occupation-difference support and its existing smearing/eta scale. |
| THR-002 | fixed in parent | `services/minimax/src/minimax/door.py:559-588` | Decimal cache-key rounding used to turn a positive scaled tolerance below `5e-15` into exactly zero.  The key now retains significant digits and refuses nonpositive requests. |
| THR-003 | fixed `c281bed3` | `services/minimax/src/minimax/solver.py:205-216,572-581,807-824`; `services/minimax/src/minimax/door.py:591-641` | All three offline node ladders return their last rule when the error target is unmet.  The service door used to announce that rule as served.  A common achieved-error postcondition now refuses fresh and cached exhausted rules. |
| THR-004 | fixed in parent + `c281bed3` | `src/gw/sc_iteration.py:2480-2486,3123,3654-3656,3769-3771,4024-4026` | The metal partition is now rebuilt from each map's live spectrum and mu, but both convergence loops still used masks frozen from the DFT seed.  `SCOutputs.partition` now carries the map-local masks into the one-shot, linear, and rCROP verdicts. |
| THR-005 | open, high | `src/gw/minimax_screening.py:845-848,920-924,1006-1009` | Public quadrature wrappers silently floor invalid interval endpoints, crossing range, target, eps_q, and node ceilings.  Bad requests therefore bypass the service's validators.  These values should be validated and refused; no physical default can be inferred here. |
| THR-006 | open | `services/minimax/src/minimax/door.py:618-635` | Runtime-solve cache coordinates `log(R)`, `omega_hat`, `A_dim`, and `eps_q` still round to 12 decimal places.  Tiny line heights can collapse to zero and distinct target functions can alias.  Unlike shipped lookup, a cache hit is not revalidated on the exact request. |
| THR-007 | open | `src/gw/mpa/sigma_windows.py:282-292` | The legacy damped-rule cache rounds both pole-width bounds to 12 decimal places.  A sufficiently narrow pole can alias the zero-width or a neighboring rectangle and reuse a rule certified for different damping, without a live residual check. |
| THR-008 | open | `src/gw/efermi.py:556-583,650-658` | When the requested step fill occupies the complete finite band ladder, the Fermi level is not determined by the data.  The kernel silently returns `E_top + 1.0` in whatever energy unit the caller used; the host range check explicitly admits that case.  It should refuse and request an empty frontier band. |
| THR-009 | open | `src/gw/sc_iteration.py:1381-1392` | Fixed-Sigma EVSC builds its grid partition and required coverage mask once from the DFT ladder.  Its fixed-N metallic mu and eigenvalues move inside `_fixed_map`, but the mask never re-anchors, reproducing the stale-SC-partition shape in the EQP2 path. |
| THR-010 | open | `src/gw/sc_iteration.py:4257-4289` | The head-window degeneracy gate calls absence of a band above the window “not a pass” but returns normally.  A truncated spectrum therefore silently passes the gate that cannot audit its own top edge. |
| THR-011 | open, measure before change | `src/gw/minimax_screening.py:730-748` | The GN-PPM two-point fit declares `|Wc(0)-Wc(z)| <= 1e-14` unsafe in absolute W units and substitutes a fallback pole.  The scale is not normalized by the local W pair; a large or tiny system can change classification under pure rescaling.  The fallback is counted, but accepted rather than refused. |
| THR-012 | open | `services/minimax/src/minimax/door.py:356-372` | `noncrossing_kappa0` silently turns `R<=1` into `1+1e-12` before measuring amplification.  An invalid/degenerate range should refuse at the door rather than acquire a plausible kappa value. |
