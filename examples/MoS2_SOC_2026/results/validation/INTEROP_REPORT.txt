ranks with eight OpenMP threads, using the native exported bsemat.h5 and

Holding BGW QP corrections fixed, the native exported kernel reproduces the
original BGW exciton energies to RMS 4.493 meV/max 6.385 meV over the first 40,

By contrast, native internal BSE is 840.7247 meV above BGW consuming the native
kernel with the native QP source. Its fine gap differs by only about 9.9 meV
from that consumer. The dominant residual therefore belongs to native fine
kernel/interpolation consumption, rather than a generic mismatch of exported
screening or file format. This does not establish which internal equation or
interpolation approximation is responsible. The native internal route uses 22
coarse conduction states; the exported kernel and BGW consumer use 12. That
distinction is retained explicitly rather than claiming identical algorithms.

EQP format defect exposed by the real reader
The first attempt stopped before reading the kernel with 'Missing k-points in
file eqp_co.dat'. Both canonical native eqp1.dat and write_bgw_eqp's expanded
file begin with '# Generated by LORRAX ...'. BerkeleyGW 4.0 Common/eqpcor.f90:104
reads a numeric k vector and count directly, treats any nonzero iostat as this
error, and does not skip comments. The controlled retry removed only comment
lines from the isolated diagnostic files and then both complete calculations
passed. Every numerical row is unchanged. Initial output and timing are kept;
canonical native files were never edited. This is a genuine EQP reader-format
incompatibility, independent of the BSE physics discrepancy.

Final coarse-point and fixed-writer controls
Native BSE on the authored 3x3 coarse grid completed all 432 roots in 24.8 s.
BGW using the same exported kernel/native QP on that grid completed in 3.10 s.
Their lowest excitons are 1.6644602 and 1.6728479 eV (native minus BGW:
-8.3877 meV); QP gaps are 3.20840 (rounded native report) and 3.2084331 eV;
bindings are 1.5439398 and 1.5355852 eV. This S1 trend supports an interpolation
or method contribution to the fine-grid discrepancy, but does not prove a
particular implementation defect or coarse spectral parity. First 8 sorted
roots differ by RMS303.20 meV/max467.79 meV, first 40 by RMS162.51 meV, and all 432
by RMS78.54 meV/max467.79 meV. Degeneracy/order patterns differ.

The original shifted 2b WFN header carries all 12 spatial operations, which
unfold it to 27 points. Only its four operations preserving q0=(.001,0,0) yield
the correct 9-point shifted grid. Disposable coarse/fine/shifted header copies
use that common subgroup to satisfy BGW's strict header checks. All coefficient
and G-vector payload hashes remain identical; standard BGW hdf2wfn converted
the copies. No additional DFT or fabricated wavefunction states were used.

The final coarse BGW run used UNSTRIPPED output from fixed writer commit
f9ef4a6a93c5971a586bbd4b5ccac965e6d2bf05. All nine numeric k blocks are byte-for-byte
identical to the previous control, followed by the provenance footer. It passed

proof includes the writer-module SHA256 and resulting EQP-file SHA256 in
coarse_grid/COMPARISON.json. The format defect is therefore repaired, and the
authorized canonical ASCII regeneration was handed back to its owner.
