## Inherited χ covariance probes

The files `inherited_chi_probes.json` and report.md preserve exact inherited step receipts for Si probes34–36. There are 28 antiunitary q rows, but CT is 6–8×10^-17. Relative CT errors near two are noise-scale diagnostics, not a pass of the time-odd polar rule. Probe34's corrected TT failed at order unity; probes35–36's raw TT covariance errors are about5×10^-10. The new toy checks CT>0.1 and a wrong TR sign produces an O(1) mismatch. This makes the formerly blind algebra observable without attributing a production QP effect to an almost-zero channel.

## What the new oracles still do not prove

The toy's final band-unfold test uses a complete occupied Hilbert space and a symmetry-invariant interaction, making G=I. It is deliberately non-diagonal and complex in band space, but is not a partially occupied no-pair screened deck. The stronger arbitrary-weight/all16 contraction test compares each parent to an explicit full-k sum; it cannot use an arbitrary noncovariant interaction to certify a final band-star unfold. These are separate tests with separate assumptions.

All row tables in production paths come from SymMaps. The independent action test checks those tables against explicit Pauli algebra, but uses the service's spatial/SU2 representation; it does not independently regenerate a crystal's symmetry from atomic positions or authenticate magnetic rows from QE. Native CPU FFT/GEMM/LU replacements validate algebra, not vendor ABI, GPU distribution performance or peak memory. No new production fix is proposed on these tests alone.

## Running the delivered gate

The delivered `tests/multi_device/bispinor_physics_oracles.py` is an explicit CPU gate, deliberately outside ordinary `test_*.py` discovery. Run it through the campaign's pinned CPU launcher/rank wrapper with `JAX_PLATFORMS=cpu JAX_ENABLE_X64=1 XLA_FLAGS=--xla_force_host_platform_device_count=4`; pass its file path explicitly to pytest. `08_delivery_cpu/{runner.sh,payload.sh,rankwrap.sh}` is the reproducible invocation. Its four-device/backend assertions fail an incorrectly configured invocation rather than silently skipping cells. The move from the run07 file path changes only the relative location of the Si WFN fixture.
