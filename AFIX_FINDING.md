# AFIX finding — ten passes is not a universal planning budget

A fixed pass count is a reproducible numerical-work allowance, not a universal
planning cost optimum or strict wall bound. The candidate keeps default10 and
uses the existing seconds key as a cooperative refusal watchdog. It never
accepts the intermediate rule selected by a timeout in step mode. A basis
attempt or removal pass can overrun; a hard wall limit requires the existing
whole-step supervisor. No asynchronous interruption or extra user dial added.

The synchronous algorithm cannot simultaneously promise completion on every
arbitrary system, a strict fixed wall limit, and clock-independent numerical
work. This is a limitation of the proposed shape, not evidence that ten passes
is inaccurate. The measured-domain replay below will distinguish completed
certified rules from timed refusals. No universal cost optimum is claimed.
