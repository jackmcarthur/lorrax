# 1.1 What LORRAX is

LORRAX is the LOw-scaling Real-space Real-Axis eXcited state package in BerkeleyGW:
a GW-BSE code scaling as $O(N^3)$ in system size and $O(N_k \log N_k)$ in k-points,
built with JAX to run on GPU and CPU clusters, GPUs primary. It is the first code to
combine several recent scaling breakthroughs in one pipeline — ISDF compression of
the real-space basis (Ch. 5), separable time-domain evaluation of all energy
denominators (Ch. 4), lattice-FFT Brillouin-zone sums (§4.3) — plus novel algorithms
of its own: real-axis minimax quadrature for $\chi(\omega)$ and $\Sigma(\omega)$
without analytic continuation (Ch. 7), and a four-density bispinor GW with the Breit
interaction (Ch. 8).

Input is a Quantum ESPRESSO calculation exported to the BerkeleyGW `WFN.h5` format.
Output: quasiparticle corrections (static COHSEX or Godby–Needs plasmon-pole),
$\Sigma_{ij\mathbf{k}}(\omega)$ on a dense real-frequency grid, Bethe–Salpeter
absorption spectra, and interpolated quasiparticle band structures. The speedups
come with memory tradeoffs relative to the canonical $O(N^4)$ plane-wave formalism
in BerkeleyGW — quantified in §1.3 and §4.3.

The GW driver is GWJAX (`gw.gw_jax`); the two names are used interchangeably, like
`pw.x` and QE.
