# 1.1 Introduction to LORRAX

LORRAX is the LOw-scaling Real-space Real-Axis eXcited state package in BerkeleyGW:
a GW-BSE code scaling as $O(N^3)$ in system size and $O(N_k \log N_k)$ in k-points,
built with the JAX distributed computing library to run natively on GPU and CPU clusters. It is the first production code to
combine several recent scaling breakthroughs in one pipeline: the space-time GW formalism with ISDF compression of
the real-space basis (Ch. 5), evaluation of all frequency integrals via integral quadrature on the real-time axis (Ch. 4), and fast Fourier transform-based implementations of Brillouin zone integrals (§4.3). It also contains
novel algorithms of its own, chiefly a real-axis minimax quadrature for
$\chi(\omega)$ and $\Sigma(\omega)$ that avoids analytic continuation (Ch. 7), an $O(N_k \log N_k)$ ISDF basis fitting algorithm (Ch. 5), and a
four-density bispinor GW with the Breit interaction (Ch. 8).

GW and BSE calculations with LORRAX require a reference Quantum ESPRESSO calculation exported to the BerkeleyGW `WFN.h5` format.
The outputs, GW quasiparticle bandstructures (static COHSEX or Godby–Needs plasmon-pole),
$\Sigma_{ij\mathbf{k}}(\omega)$ on a dense real-frequency grid, Bethe–Salpeter
absorption spectra, and interpolated quasiparticle band structures, are delivered in the same file formats as the existing BerkeleyGW package. LORRAX provides significant speedups at the cost of a larger memory workspace relative to the canonical $O(N^4)$ plane-wave formalism
in BerkeleyGW, quantified in §1.3 and §4.3.
