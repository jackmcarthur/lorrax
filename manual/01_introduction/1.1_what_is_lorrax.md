# 1.1 What LORRAX is

LORRAX (**LO**w-scaling **R**eal-space **R**eal-**A**xis e**X**cited state package) is a
many-body perturbation theory code for computing quasiparticle band structures and
optical excitations of periodic and isolated systems. Its core is a GW implementation
whose cost grows as $O(N^3)$ in system size and as $O(N_k \log N_k)$ in the number of
Brillouin-zone sampling points — the latter scaling, to our knowledge, unique among
production GW codes. Both properties follow from two design decisions made everywhere
and without exception:

1. **Work in a compressed real-space basis.** All two-point objects of the theory —
   the Green's function $G(\mathbf{r},\mathbf{r}')$, the polarizability
   $\chi(\mathbf{r},\mathbf{r}')$, the screened interaction $W(\mathbf{r},\mathbf{r}')$,
   the self-energy $\Sigma(\mathbf{r},\mathbf{r}')$ — are represented on a small set of
   interpolation points selected by Interpolative Separable Density Fitting (ISDF,
   Chapter 5), rather than in a plane-wave product basis.

2. **Integrate frequency and time with a handful of optimized nodes.** Energy
   denominators are rendered separable by exact time-domain representations, evaluated
   on minimax-optimized quadrature grids whose size does not grow with system size
   (Chapters 4 and 7). Dynamical quantities are obtained on the *real* frequency axis —
   no analytic continuation from imaginary frequencies is ever performed.

LORRAX is written in Python on [JAX](https://github.com/jax-ml/jax) and runs the same
source on NVIDIA GPUs (its primary target), on CPUs, and on anything from one device to
hundreds across many nodes. Distributed execution uses a single 2D device mesh over
which all large arrays are sharded (Chapter 13); optional native extensions provide
parallel HDF5 I/O and distributed dense linear algebra (Chapter 2).

The code consumes standard DFT output: plane-wave wavefunctions from Quantum ESPRESSO,
converted to the BerkeleyGW `WFN.h5` format. It produces quasiparticle corrections
(static COHSEX or dynamically screened GW with a Godby–Needs plasmon-pole treatment of
the frequency dependence), full frequency-resolved self-energy matrix elements
$\Sigma_{ij\mathbf{k}}(\omega)$, Bethe–Salpeter absorption spectra, and interpolated
quasiparticle band structures.

The GW driver module is called **GWJAX** (`gw.gw_jax`), and the name is used
interchangeably with LORRAX in the same way `pw.x` is used for Quantum ESPRESSO.
