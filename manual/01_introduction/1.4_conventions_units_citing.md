# 1.4 Units, notation, citing

Internally: Rydberg atomic units ($\hbar = 2m_e = e^2/2 = 1$). All output energies
in eV unless labeled Ry. Input keys carry units in the name where ambiguous
(`sigma_omega_min_ev`, `degen_avg_tol_ry`). Band energies are measured from the
chemical potential (midgap by default, `fermi_reference`), so
$\varepsilon_v < 0 < \varepsilon_c$.

| Symbol | Meaning |
|---|---|
| $\psi_{n\mathbf{k},s}(\mathbf{r})$ | Bloch spinor: band $n$, k-point $\mathbf{k}$, spinor component $s$ |
| $c_{n\mathbf{k},s}(\mathbf{G})$ | plane-wave coefficients; $\psi = N_r^{-1/2}\sum_\mathbf{G} c\, e^{i(\mathbf{k}+\mathbf{G})\cdot\mathbf{r}}$ |
| $\mathbf{r}_\mu$, $n_\mu$ | ISDF interpolation points (centroids) and their count |
| $\zeta_{q,\mu}(\mathbf{r})$ | ISDF interpolation vectors at momentum transfer $\mathbf{q}$ |
| $\mathbf{R}$ | Born–von Kármán lattice vector, conjugate to $\mathbf{k}$ |
| $v$, $c$ | valence and conduction band indices |
| $G$, $\chi$, $W$, $\Sigma$ | Green's function, polarizability, screened interaction, self-energy |
| $N$, $N_k$, $N_r$ | system size, k-point count, FFT grid size |

Full glossary: Appendix F.

Cite the LORRAX methods paper (reference upon publication); for the frequency
integration, Kim, Martyna & Ismail-Beigi, PRB **101**, 035139 (2020); for the
plasmon-pole model, Godby & Needs, PRL **62**, 1169 (1989). Full bibliography:
Appendix G.
