# 1.4 Units, notation, and citing

**Units.** LORRAX works internally in Rydberg atomic units ($\hbar = 2m_e = e^2/2 = 1$;
energies in Ry, lengths in Bohr). All energies in output files and in this manual's
worked examples are reported in **eV** unless a Ry label is explicit. Input keys carry
their unit in the name where ambiguity is possible (`sigma_omega_min_ev`,
`degen_avg_tol_ry`).

**Notation** (full glossary: Appendix F).

| Symbol | Meaning |
|---|---|
| $\psi_{n\mathbf{k},s}(\mathbf{r})$ | Bloch spinor: band $n$, k-point $\mathbf{k}$, spinor component $s\in\{\uparrow,\downarrow\}$ |
| $c_{n\mathbf{k},s}(\mathbf{G})$ | plane-wave coefficients; $\psi = N_r^{-1/2}\sum_\mathbf{G} c\, e^{i(\mathbf{k}+\mathbf{G})\cdot\mathbf{r}}$ |
| $\mathbf{r}_\mu$, $n_\mu$ | ISDF interpolation points (centroids) and their count |
| $\zeta_{q,\mu}(\mathbf{r})$ | ISDF interpolation vectors at momentum transfer $\mathbf{q}$ |
| $\mathbf{R}$ | Born–von Kármán lattice vector (conjugate to $\mathbf{k}$ under the lattice FT) |
| $v$, $\varepsilon$ or $c$ | valence (occupied) and conduction (empty) band indices |
| $G$, $\chi$, $W$, $\Sigma$ | Green's function, polarizability, screened interaction, self-energy |
| $N$, $N_k$, $N_r$ | system size measure, number of k-points, FFT grid size |

Occupied/empty energies are measured from the chemical potential $\mu_F$ (midgap by
default, `fermi_reference`), so that $\varepsilon_v < 0 < \varepsilon_c$ and
time-domain exponentials decay in the directions the formalism requires.

**Citing.** Cite the LORRAX methods paper (reference to be inserted upon publication);
for the frequency-integration machinery additionally cite Kim, Martyna & Ismail-Beigi,
Phys. Rev. B **101**, 035139 (2020), and for the plasmon-pole model Godby & Needs,
Phys. Rev. Lett. **62**, 1169 (1989). The full method bibliography is collected in
Appendix F.
