# 1.2 Capabilities

| Capability | Status | Where |
|---|---|---|
| Static COHSEX quasiparticle corrections | production | Ch. 4, 7 |
| GN-PPM $G_0W_0$ with $\Sigma(\omega)$ on a real-frequency grid | production | Ch. 7 |
| Self-consistent Σ loop (QSGW-style rotations, rCROP-accelerated) | beta | §4.5 |
| Bispinor GW: charge-channel screening + bare-Breit transverse exchange | production (one-shot) | Ch. 8 |
| Bethe–Salpeter absorption (Haydock / Lanczos / Davidson / FEAST) | production | §9.2 |
| Quasiparticle band-structure interpolation | production | §9.3 |
| DFT operator toolbox ($V_H$/$V_{xc}$ reconstruction, dipoles, Sternheimer) | production | §9.1 |
| 3D bulk / 2D slab Coulomb geometries | production | Ch. 6 |
| 0D box Coulomb truncation | kernel implemented; driver wiring pending | §6.1 |
| Multi-node GPU execution, distributed linear algebra, parallel I/O | production | Ch. 12 |
| CPU-only execution (same source) | supported | Ch. 2 |

Not yet available: screened bispinor W (the Breit channel is bare exchange only,
§8.4); spinless or non-SOC spin-polarized calculations (every calculation is
two-component spinor, §5.2); DFT input other than Quantum ESPRESSO via the
BerkeleyGW format; spin-polarized $V_{xc}$ reconstruction in the standalone DFT
toolbox (§9.1; the GW pipeline is unaffected).

Every mode is exercised by the test suite on a single GPU; frozen end-to-end gates
(Si COHSEX vs. BerkeleyGW, MoS₂ GN-PPM, bispinor GN-PPM) define the numbers a fresh
install must reproduce (§13.5).
