# 1.2 Capabilities at a glance

| Capability | Status | Where documented |
|---|---|---|
| Static COHSEX quasiparticle corrections | production | Ch. 4, 7 |
| GN-PPM G₀W₀ with full Σ(ω) on a real-frequency grid | production | Ch. 7 |
| Self-consistent Σ loop (QSGW-style rotations, rCROP-accelerated) | supported (beta) | §4.5 |
| Bispinor GW: charge-channel screening + bare-Breit transverse exchange | production (one-shot) | Ch. 8 |
| Bethe–Salpeter absorption (Haydock / Lanczos / Davidson / FEAST) | production | §9.2 |
| Quasiparticle band-structure interpolation | production | §9.3 |
| DFT operator toolbox (V_H/V_xc reconstruction, dipoles, Sternheimer) | production | §9.1 |
| 3D bulk / 2D slab Coulomb geometries | production | Ch. 6 |
| 0D box Coulomb truncation | kernel implemented; driver wiring pending | §6.1 |
| Multi-node GPU execution, distributed linear algebra, parallel I/O | production | Ch. 12 |
| CPU-only execution (same source) | supported | Ch. 2 |

**Not yet available** (stated here so nobody discovers it on page 40):

- *Screened* bispinor W — the Breit channel is currently bare exchange only; the
  transverse Dyson inversion is on the roadmap (§8.4).
- Spinless or non-SOC spin-polarized calculations: every LORRAX calculation is a
  two-component-spinor calculation (§1.3, §5.2). Light-element systems run correctly
  but pay the spinor price.
- DFT front ends other than Quantum ESPRESSO via the BerkeleyGW `WFN.h5` format.
- Spin-polarized $V_{xc}$ reconstruction in the standalone DFT-operator toolbox
  (§9.1); the GW pipeline itself is unaffected.

Every mode above is exercised by the automated test suite on a single GPU; the frozen
end-to-end gates (Si COHSEX vs BerkeleyGW, MoS₂ GN-PPM, bispinor GN-PPM) define the
numbers a fresh install must reproduce (§13.5).
