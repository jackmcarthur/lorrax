# 2.2 Pure-Python install

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
git clone <lorrax-repo-url> && cd lorrax
uv sync
uv run python -m gw.gw_jax -i tests/regression/cohsex_debug/cohsex_test.in
uv run python -m pytest -q
```

The fixture runs a complete static-COHSEX calculation on a fresh clone with no GPU
and no native build; it ships its own wavefunction, centroids, dipoles, and
kinetic/ionic data. A CPU-only environment runs identically with JAX's CPU backend.

This tier is correct at any scale but serializes at large scale: HDF5 traffic falls
back to gather-to-rank-0 (`slab_io = allgather`), and dense factorizations gather to
single devices, which caps $n_\mu$ at single-device memory. Use it for serial work,
development, and single-node runs; for multi-node production the native stack
(§2.3) is part of the install, not a tuning option.
