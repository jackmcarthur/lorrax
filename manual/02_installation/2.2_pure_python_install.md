# 2.2 The pure-Python install (serial and single-node tier)

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh     # one-time: install uv
git clone <lorrax-repo-url> && cd lorrax
uv sync                                             # editable install, all Python deps
```

Verify with the bundled fixture — a complete static-COHSEX calculation that ships its
own wavefunction, centroids, dipoles, and kinetic/ionic data, and needs **no GPU and
no native build**:

```bash
uv run python -m gw.gw_jax -i tests/regression/cohsex_debug/cohsex_test.in
uv run python -m pytest -q          # the same fixture as a regression test
```

If that runs, LORRAX works on your machine and Chapter 3 will make sense end to end.

**What this tier is for — and what it is not.** Understand what you have just
installed: every physics feature, with single-process parallelism over however many
GPUs one process can see. What you have *not* installed are the collective layers.
Without them:

- **I/O serializes.** Large HDF5 traffic (the ζ store, Σ(ω), restart bundles) falls
  back to gather-to-rank-0 writes (`slab_io = allgather`). Fine for one node;
  a real bottleneck — minutes, not seconds, per checkpoint — at scale.
- **Dense linear algebra gathers.** Factorizations that the FFI stack would run
  distributed are executed after gathering matrices to single devices, which both
  costs time and puts a hard $n_\mu$ ceiling at single-device memory
  (felt first in band-structure interpolation, §9.3, and large-basis ζ fits).

This is why the support statement of §2.1 is worded the way it is: **the pure tier is
the correct install for serial work, development, and single-node runs; for any
multi-node production calculation the native stack of §2.3 is strongly
recommended** — treat it as part of "installing LORRAX on a cluster," not as an
optional optimization.

GPU note: the default dependency extra targets CUDA 13 (`jax[cuda13]`); a CPU-only
environment installs and runs identically with JAX's CPU backend — same source, same
inputs, same outputs, longer wall-clock.
