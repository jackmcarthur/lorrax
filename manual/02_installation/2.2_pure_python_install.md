# 2.2 Minimal host install

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
git clone <lorrax-repo-url> && cd lorrax
uv sync
./src/ffi/cpp/build_host.sh
uv run python -m gw.gw_jax -i tests/regression/cohsex_debug/cohsex_test.in
uv run python -m pytest -q
```

The fixture runs a complete static-COHSEX calculation with no GPU and ships its
wavefunction, centroids, dipoles, and kinetic/ionic data. The native host library
is nevertheless required: the serial h5py/allgather fallback and its deck selector
were deleted because they violated the distributed memory contract. See §2.3 for
the native dependencies needed by `build_host.sh`.
