# 2.4 Site recipes

NERSC Perlmutter (reference platform, 4× A100 nodes, Cray MPICH, Shifter):

```bash
# one-time
vi config/perlmutter/site_config.sh    # account, QoS, paths
bash config/perlmutter/install.sh      # installs the Lmod module

# every session
module load lorrax
lxalloc                                # 1 node / 4 GPUs, exports SLURM_JOBID
lxpre cohsex.in 640                    # centroids + dipole.h5 + kin_ion.h5
lxrun python3 -u -m gw.gw_jax -i cohsex.in
```

`lxrun` handles the process-per-GPU `srun`, container bind-mounts, and staged native
libraries; details in `config/README.md`.

Generic SLURM: one process per GPU, JAX distributed initialization from the SLURM
environment, native libraries on `LD_LIBRARY_PATH` if built.

```bash
#SBATCH --nodes=2
#SBATCH --ntasks-per-node=4        # = GPUs per node
#SBATCH --gpus-per-node=4

srun python3 -u -m gw.gw_jax -i cohsex.in
```

Container users (Apptainer/Singularity, `--nv`) bind-mount the source tree and
library prefixes; the Shifter path in `config/` is the worked example.

Workstation: `uv sync` and go (§2.2). Set `memory_per_device_gb` to VRAM minus
~2 GB headroom; the memory planner (§12.2) reports when a system has outgrown the
card.
