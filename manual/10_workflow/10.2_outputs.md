# 10.2 Outputs

| File | Contents |
|---|---|
| `eqp0.dat`, `eqp1.dat` | k-point, band, $\varepsilon^{DFT}$, $\varepsilon^{QP}$ (eV); eqp0 = zeroth-order, eqp1 = Z-linearized (§4.5); BerkeleyGW `eqp.dat` format |
| `sigma_diag.dat` | per-state Σ decomposition (X, SX, COH or dynamic branches), log-formatted |
| `sigma_mnk.h5` | full $\Sigma_{ij\mathbf{k}}(\omega)$ on the ω grid (`sigma_omega_h5_file`); datasets per k, band pair, frequency |
| `qp_rotations.h5` | quasiparticle unitaries per k; consumed by `postprocess.rotate_wfn_to_qp` and the SC loop |
| `zeta_q.h5` / per-q ζ store | ISDF vectors on disk (10–100 GB class); the restart's expensive asset |
| `isdf_tensors_<n_rmu>.h5` | tagged-array restart bundle (centroid ψ values, $V_q$, fit metadata) |

Formats are BerkeleyGW-compatible where an equivalent exists; dataset-level
specifications are in Appendix D. Console output narrates the pipeline stages with
timings and the fit censuses (ζ residuals, plasmon-pole validity, §7.4); it is the
first place to look when a number surprises.
