# 10.1 Required inputs and preprocessing

Every GW run consumes four files, all referenced from `cohsex.in`:

| File | Produced by | Needed for |
|---|---|---|
| `WFN.h5` | QE → `pw2bgw.x` → `wfn2hdf.x` | everything |
| `centroids_frac_<N>.txt` | `python -m centroid.kmeans_cli <N> --seed 42` | ISDF basis (Ch. 5) |
| `dipole.h5` | `python -m psp.get_dipole_mtxels -i cohsex.in` | $q\to0$ head (App. B) |
| `kin_ion.h5` | `python -m gw.kin_ion_io -i cohsex.in` | QP equation, band structures |

plus `centroids_frac_<M>_current.txt` for bispinor runs (§8.2) and `vxc.dat` /
`kih.dat` from `pw2bgw.x` (§3.1). The three preprocessing commands run in seconds
to minutes and once per system; on Perlmutter `lxpre cohsex.in <N>` runs all
three. Centroid generation is the only stochastic step; the seed is recorded in
the file header, and orbit closure (§5.4) may raise the count above the request.
