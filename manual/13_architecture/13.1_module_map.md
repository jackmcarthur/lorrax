# 13.1 Module map

| Package | Contents |
|---|---|
| `gw/` | the GW driver (`gw_jax.py`), input/config (`gw_config.py`, `gw_init.py`), screening (`w_isdf.py`, `minimax_screening.py`), Σ kernels (`cohsex_sigma.py`, `ppm_sigma.py`, `sigma_x_bispinor.py`), Coulomb (`coulomb/`, `vcoul.py`, `v_q_g_flat.py`, `v_q_bispinor.py`), head correction, QP solvers (`sigma_dispatch.py`, `sc_iteration.py`, `eqp_bgw.py`), memory planner |
| `isdf/` | the ζ-fit engine (`core.py`: CCT/ZCT accumulation, per-channel factorization, solves) |
| `centroid/` | k-means/CVT generation, charge and current density weights, orbit closure |
| `common/` | `meta.py` (system metadata), `symmetry_maps.py`, minimax solvers + shipped tables, FFT helpers, bispinor lift, ψ(G) host store |
| `file_io/` | `WfnLoader`, `SlabIO` (backend-dispatched parallel writes), ζ loader, restart tagged arrays, output writers |
| `ffi/` | the native layer: per-library subdirs (cusolvermp, cublasmp, slate, phdf5, scalapack) behind one `liblorrax_ffi.so` |
| `bse/`, `bandstructure/`, `psp/`, `solvers/`, `mixing/`, `postprocess/` | Chapters 9 and 4.5 |
| `runtime/` | distributed initialization, padding, AOT memory hooks |

The driver reads as the pipeline outline: `gw_init` (config, metadata, planner) →
ζ fit → $V_q$ → screening → `sigma_dispatch` → QP solve → outputs, with the
self-consistent loop wrapping the middle (`sc_iteration.run_sc_driver`).
`AGENTS.md` in the repository root maps files to debugging tasks and states the
coding standards.
