# 13.4 Testing and the frozen gates

`uv run python -m pytest -q` runs the full suite on one GPU (or CPU) in about four
minutes; no multi-GPU hardware is ever required, since the code ships to users on
arbitrary device counts. Three tiers:

1. Frozen end-to-end pins: complete GW runs against golden outputs: Si static
   COHSEX versus a BerkeleyGW reference, an IBZ-stored-wavefunction COHSEX, MoS₂
   GN-PPM, and bispinor GN-PPM. These define the numbers a fresh install must
   reproduce and are re-frozen only deliberately, with the re-freeze recorded.
2. Invariance gates, run as restart variants of a shared session state:
   restart ≡ fresh and IBZ ≡ full-BZ (bit-identical), self-consistent iteration 1
   ≡ one-shot, accumulation modes equal at ~1e-13, padding and fixed-point
   rotation invariances.
3. Unit tests, plus the FFI contract suite (§12.3), which self-skips cleanly when
   the native stack is absent.

The invariance gates are the working definition of correctness for the machinery
of Chapters 5–7: any change that breaks one is wrong until proven otherwise.
Multi-rank behavior is exercised by the contract suite's CLI mode under a real
launcher; `pytest-xdist` parallelizes the plain suite across local GPUs.
