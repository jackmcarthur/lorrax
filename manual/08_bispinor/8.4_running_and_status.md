# 8.4 Running a bispinor calculation; status

A bispinor run is the scalar input plus:

```ini
bispinor = true
centroids_file          = centroids_frac_640.txt          # charge set
centroids_file_current  = centroids_frac_209_current.txt  # transverse set
```

with the second centroid file generated by
`python -m centroid.kmeans_cli <M> --density-mode current`. Every
`compute_mode` runs in the default `bispinor_gw = bare_transverse`; the
bispinor GN-PPM regression gate is one of the frozen test-suite pins (§13.5).
Plan band counts about 3× below the scalar ceiling for the same hardware
(§8.2), or let the planner refuse for you. Two optional Γ-cell dials:
`bispinor_tt_head_correction = true` adds the bare transverse head (§8.1's
missing $\mathbf K = 0$ slot in the TT blocks), and `head_correction` governs
the charge head as in a scalar run.

## Status

*As of `integ/bispinor-static-cleanup-2026-09-01@3897f89f`, 2026-09-01 — a
branch, not `origin/main`, which still has two packed modes. The authority is
`docs/theory/four-current-head-corrections.md` §1, which carries this as a
table; do not re-derive it here.*

**Built and in production.** One-shot DHF + bare-Breit exchange on top of
charge-channel screening, static or dynamic (`cohsex`, `gn_ppm`, `hl_ppm`,
`mpa`), on four-component wavefunctions. Two centroid sets, four ζ fits, the
sixteen bare $D^{IJ}$ tiles, the bare TT Γ-cell head, and the four-spinor
G-space current Hartree.

**Built, experimental.** Transverse *screening* does exist, as **one** packed
static mode: `bispinor_gw = full_static_cohsex` solves the coupled
sixteen-block Lorentz Dyson equation $W = (1 - D\chi_0)^{-1}D$ and contracts
all sixteen $W^{IJ}$ into $\Sigma$. The Γ-cell completion runs by default
(under `head_correction = full`); the Hall term inside it is optional, and
defaults to zero when no `static_gauge_hall_file` is present — which is the
exact answer for a Chern-trivial insulator. The mode is refused outside
`compute_mode = cohsex`, insulators only, one shot, and slab geometry only
while the completion is on. The older `charge_hall_cubature` spelling now
refuses, naming this mode.

Inside that same envelope the **default** `bare_transverse` now runs through
the same packed operator, with the twelve current $\chi$ blocks declared
zero, so $W_{\rm packed} = \mathrm{diag}(W_{00}, D_{TT})$ and $\Sigma^B$ is
the TT part of the sixteen-block $\Sigma_X$. The body is byte-identical to
the older route; the $q\to0$ head is not, and the two head quadratures
disagree by 5.4 meV MAE on MoS2 3x3 — an open question, `docs/theory/
four-current-head-corrections.md` §3.6. Outside the envelope (bulk, the
dynamic modes, `x_only`, self-consistent) the older route is unchanged and is
the only certified one. `bispinor_tt_head_correction` is refused inside the
envelope, where the completion already supplies that head.

**Not built.** A *dynamic* photon propagator $D^{IJ}(\omega)$ or
$W^{IJ}(i\omega_p)$. Every dynamic self-energy screens the charge channel only
and adds $\Sigma^B$ as a bare exchange term, so "GN-PPM bispinor" means
charge-channel GN-PPM plus bare Breit. Frequency dependence in this code is
charge-only.

**`off` is a debug skip, not a mode.** A packed screened variant that
*requires* `head_correction = off` would be headless at $q \to 0$ and is a
defect under the 2026-09-01 ruling (`docs/architecture/decisions.md`): COHSEX
with bispinors always carries the Γ-cell head. `off` is still accepted for
convergence studies, behind a loud `DEBUG` banner that is also written into
the run record; `no_local_fields` is refused, the coupled solve having no
scalar diagnostic head.

**Self-consistency.** Bispinor QSGW is static-only, and a bispinor
self-consistent run with `density_self_consistent = false` refuses.

Expected magnitudes at production settings: Breit corrections to individual
quasiparticle levels are tens of meV in 4d/5d and halide systems, sub-meV in
light-element solids, consistent with the $\alpha_{\rm FS}^2$ scaling of §8.1.
The difference between screened and unscreened Breit was measured once, on FM
CrI3, at under 10 μeV.
