# 8. Bispinor GW

Two-component GW misses the $O(\alpha_{\rm FS}^2)$ relativistic corrections to
the electron–electron interaction: the small-component charge and the
transverse (Breit) exchange between currents. A bispinor run lifts the DFT
two-spinors to Dirac four-spinors by kinetic balance and adds both. The deck
is the scalar deck plus

```ini
bispinor = true
centroids_file          = centroids_frac_640.txt          # charge set
centroids_file_current  = centroids_frac_209_current.txt  # current set
```

with the current set from `python -m centroid.kmeans_cli <M> --density-mode current`.
`bispinor_gw` chooses the route; the default is `bare_transverse`.
