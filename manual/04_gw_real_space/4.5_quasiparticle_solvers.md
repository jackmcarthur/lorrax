# 4.5 From Σ to quasiparticle energies

With $\Sigma_{ij\mathbf{k}}(\omega)$ in hand, quasiparticle energies solve

$$
\varepsilon^{QP}_{n\mathbf{k}} \;=\; \varepsilon^{DFT}_{n\mathbf{k}}
+ \big\langle n\mathbf{k} \big|\, \Sigma(\varepsilon^{QP}_{n\mathbf{k}}) - V_{xc} \,\big| n\mathbf{k} \big\rangle .
$$

The `qp_solver` input selects how literally this nonlinear equation is treated:

- **`one_shot_dft`** (default). Evaluate at the DFT energy and linearize:
  $\varepsilon^{QP} = \varepsilon^{DFT} + Z\,\langle\Sigma(\varepsilon^{DFT}) - V_{xc}\rangle$
  with the renormalization factor
  $Z = \big[1 - \partial\langle\Sigma\rangle/\partial\omega\big]^{-1}$ read off the
  sampled frequency grid. Both the zeroth-order (`eqp0`) and linearized (`eqp1`)
  values are written out, matching BerkeleyGW's convention.
- **`fixed_point`**. Solve the on-shell fixed point $\varepsilon = \varepsilon^{DFT} +
  \langle\Sigma(\varepsilon) - V_{xc}\rangle$ per state on the sampled grid — the
  proper "graphical solution" when $\Sigma(\omega)$ has structure near the QP energy.
  Dynamic (frequency-sampled) modes only.
- **`self_consistent`**. The self-consistent loop: Σ is rebuilt each iteration —
  QSGW-style, from wavefunctions rotated by the previous iteration's quasiparticle
  unitary — until stable to `sc_tol_ev`. The quadrature grids keep fixed shapes
  across iterations, so iterations after the first hit the compilation cache. The
  reported `eqp` columns keep the same at-$E_{DFT}$ formula in all three modes; only
  the provenance of Σ changes.

**Accelerating the self-consistent fixed point.** Plain iteration of
$\Sigma^{in} \mapsto \Sigma^{out}$ converges slowly or rings; standard Pulay/DIIS
mixing, designed for SCF densities, is not reliably stable for complex-valued
self-energy fixed points. LORRAX uses **rCROP** (`sc_accelerator = "rcrop"`), a
residual-history acceleration in the CROP–Anderson family [Wan & Międlar, *On the
Convergence of the CROP-Anderson Acceleration Method*; Algorithms 2.2/3.1], which we
find stable where Pulay-type mixing is not; plain linear mixing remains available as
a fallback (`sc_accelerator = "linear"`, `sc_mixing`). History depth is
`sc_history_depth` (default 5).

**Degeneracy averaging.** Symmetry-degenerate states acquire tiny artificial
splittings from ISDF and quadrature noise. Unless `no_degen_averaging` is set,
$\Sigma$ diagonal elements are averaged over degenerate multiplets (tolerance
`degen_avg_tol_ry`) before the QP equation is solved — the same convention BerkeleyGW
applies.

> **BGW correspondence.** `eqp0`/`eqp1` columns match `sigma.log`/`eqp.dat` semantics
> (`eqp0` = zeroth-order Newton at $E_{DFT}$; `eqp1` = Z-linearized; static modes have
> $Z=1$ so the two coincide). The Z-factor derivative is a central difference on the
> already-sampled ω-grid with spacing 0.5 eV — the same value as BerkeleyGW's
> `finite_difference_spacing` default — evaluated at no extra Σ cost; unlike BGW's
> `finite_difference_form` it is not user-configurable.
