# 4.4 Time integration: the working picture

The denominators $x = \varepsilon_c - \varepsilon_v$ span three to four decades,
from the gap to the band width, and one shared node set $\{t_l, w_l\}$ must
represent $1/x$ uniformly over that range. Minimax rules do this optimally
(worst-case error minimized over the interval), with node counts growing only
logarithmically in the range ratio $R = x_{max}/x_{min}$; that logarithm is why
$N_\tau \sim O(N^0)$.

Static screening denominators keep one sign
(every $\varepsilon_c - \varepsilon_v$ in $\chi^0$ is positive): $e^{-x\tau}$
decays for all terms and the integral lives on the imaginary-time axis.

Dynamic Sigma denominators can cross zero. They are handled by the shared
uniform denominator-box service, which approximates the fixed-eta reciprocal
directly and uses real or complex time support according to the box geometry.
The old HGL sine target is retired rather than retained as a fallback.

Static minimax node placement derives from the spectrum and
`minimax_target_error`; dynamic box accuracy is controlled independently by
`sigma_quadrature_eps` (§7.5).
