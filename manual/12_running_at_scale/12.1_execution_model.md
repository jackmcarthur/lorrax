# 12.1 Execution model

One Python process per GPU, launched by the scheduler (`srun`, `mpirun`, or the
`lxrun` wrapper), with `jax.distributed` initialized from the environment; the
processes form a single 2D device mesh over which all large arrays are sharded
(§13.2). The same launch shape serves the CPU backend, one process per node or per
socket. There is no separate MPI configuration: the FFI backends join the world the
launcher created. §2.4 has the SLURM templates.

Two environment knobs matter routinely: `JAX_COMPILATION_CACHE_DIR` (persistent
XLA cache; first-run compilation is minutes, cached runs are seconds) and the
allocator (`TF_GPU_ALLOCATOR=cuda_malloc_async` on the reference platform, letting
XLA and NCCL share one pool).
