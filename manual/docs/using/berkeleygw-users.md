# For BerkeleyGW users

`WFN.h5` BerkeleyGW's input keys, files and conventions, and what replaces each in LORRAX.
{: .page-summary }

LORRAX reads the same `WFN.h5` as BerkeleyGW and writes `eqp0.dat` and `eqp1.dat` in BerkeleyGW's format, but none of `epsilon.x`, `sigma.x`, `kernel.x` or `absorption.x` has a one-to-one counterpart. Keys and defaults are owned by the [GW keywords](../drivers/gw/keywords.md) and [BSE keywords](../drivers/bse/keywords.md) pages; every LORRAX key below links to its entry.

## How the work divides {: #division }

| BerkeleyGW | LORRAX | Note |
|---|---|---|
| `epsilon.x` and `sigma.x` | [`gw.gw_jax`](../drivers/gw/index.md) | One run builds $\chi^0$, $W$ and $\Sigma$; no dielectric file passes between them. |
| `kernel.x` and `absorption.x` (diagonalization) | [`bse.bse_jax`](../drivers/bse/index.md) | No kernel file: $H$ is applied matrix-free in every run. |
| `absorption.x` (`haydock`, `lanczos`) | `bse.absorption_haydock` | Same deck and restart bundle as `bse.bse_jax`. |
| `inteqp.x` | [`htransform`](../utilities/htransform.md) | QP bands on arbitrary $\bk$. |
| `kernel.x` with `exciton_Q_shift` | [`exciton-bands`](../drivers/exciton-bands/index.md) | Finite-$\bQ$ excitons. |
| `WFNq`, shifted $\bq_0$ | [`dipole`](../utilities/dipole.md) | `dipole.h5` supplies the $\bq\to0$ head. |
| `vxc.dat`, `kih.dat` | [`kin-ion`](../utilities/kin-ion.md) | `kin_ion.h5` holds $\langle m\bk\vert T+V^{\mathrm{ion}}\vert n\bk\rangle$. |
| `epsilon_cutoff` (the G basis of $\varepsilon$) | [`centroids`](../utilities/centroids.md) | `centroids_frac_<N>.txt`, the ISDF points $\br_\mu$. |

The run directory also holds QE's `data-file-schema.xml`, from which LORRAX reads the symmetry operations and time-reversal flags, and the pseudopotential files that `kin-ion` and `dipole` read. What `WFN.h5` must contain is on [Inputs from DFT](inputs-from-dft.md).

## Conceptual differences {: #concepts }

### ISDF instead of a plane-wave ε⁻¹ {: #isdf }

BerkeleyGW represents $\chi^0$, $\varepsilon^{-1}$ and $W$ as $\bG\bG'$ matrices with $|\bq+\bG|^2$ below `epsilon_cutoff`. LORRAX fits every pair density on $N_\mu$ real-space points, $\psi^*_{m\bk-\bq}(\br)\psi_{n\bk}(\br)\approx\sum_\mu\zeta_{\bq\mu}(\br)\,\psi^*_{m\bk-\bq}(\br_\mu)\psi_{n\bk}(\br_\mu)$, so $V_\bq(\mu,\nu)$, $\chi^0$ and $W_\bq(\mu,\nu;z)$ are $N_\mu\times N_\mu$ per $\bq$. $N_\mu$, the row count of the centroid table, is the basis-size parameter that replaces `epsilon_cutoff`; 10 × `number_bands` is the starting count. There is no plane-wave matrix element $M_{nm}(\bG)$ and no separate screened cutoff. Fit and accuracy: [ISDF and V(q)](../theory/isdf.md).

### χ⁰ and Σ in real time {: #real-time }

LORRAX never sums over transitions $(v,c,\bk)$ with energy denominators. $\chi^0$ is the product $-i\,G^{\gtrless}G^{\lessgtr}(-t)$ on the points at a few time nodes, formed in $\bR$ space and transformed to the complex frequencies the treatment requests by a [minimax](../theory/time-frequency.md#exponentials) rule. $\Sigma^c$ is the product $i\,G^{\gtrless}W^c$ at complex time nodes, folded onto real frequency by a quadrature certified to [`sigma_quadrature_eps`](../drivers/gw/keywords.md#sigma_quadrature_eps). One time node costs band GEMMs and lattice FFTs ([GW theory §2–3](../drivers/gw/theory.md#screening)).

### Real-axis Σ from the tangential W {: #real-axis }

The production full-frequency treatment writes $W^c_\bq$ as one set of real poles shared by every $(\mu,\nu)$, $W^c_\bq(\mu,\nu;z)=\sum_jb_{j\bq}(\mu)b^*_{j\bq}(\nu)\big[(z-\Omega_{j\bq})^{-1}-(z+\Omega_{j\bq})^{-1}\big]$, read from a Loewner pencil on fixed supports above the real axis and on the imaginary axis ([Tangential W model](../theory/tangential-w.md#model-form)). $\Sigma^c(\omega)$ then has a closed pole form and is evaluated directly on the real axis, with the retarded broadening η = [`sigma_regularization_ev`](../drivers/gw/keywords.md#sigma_regularization_ev) entered once. This route has no analytic continuation of $\Sigma^c(i\omega)$ and no real-frequency grid of $\varepsilon^{-1}$, so `frequency_dependence_method`, `cd_integration_method` and the frequency-grid keys of `epsilon.inp` have no counterpart on it. A separate contour-deformation route, [`sigma_frequency_integration`](../drivers/gw/keywords.md#sigma_frequency_integration) `= contour_deformation`, serves as a reference; its frequency sampling is compared with BerkeleyGW's on [Contour deformation §9.2](../theory/contour-deformation.md#compare-bgw). By default $\Sigma^c$ is read on shell, at $E_{m\bk}$ and $E_{n\bk}$ only. All treatments: [Frequency treatments of Σ](../theory/frequency-treatments.md#compare-table).

### The q → 0 head without q₀ {: #head }

LORRAX has no shifted-$\bq_0$ calculation and no `WFNq`. The head of $\chi^0$ is $q_aS_{ab}(z)q_b$, built from the velocity matrix elements of `dipole.h5` (nonlocal commutator included), with local fields folded in from the wings and the Γ body. $\bar v_{00}$ and $\bar W_{00}(z)$ are mini-BZ averages of $v$ and $v/(1-v\chi_{00})$ over the Γ cell. In $\Sigma$ the head is a band-diagonal, closed-form term; in the BSE it is a rank-1 tile on $V_\Gamma$ and $W_\Gamma$. BerkeleyGW's head can be imposed with [`vhead`](../drivers/gw/keywords.md#vhead), [`whead_0freq`](../drivers/gw/keywords.md#whead_0freq) and [`whead_imfreq`](../drivers/gw/keywords.md#whead_imfreq), or read from `eps0mat.h5` with [`wcoul0_source`](../drivers/gw/keywords.md#wcoul0_source) `= epshead` (static only). Details: [The q → 0 head](../theory/q0-head.md#bgw).

### Quasiparticles without a QP equation {: #qp }

LORRAX never subtracts a $V^{xc}$ and never solves a QP equation. A one-shot run builds the Hermitian matrix $H_{mn\bk}=\langle m\bk|T+V^{\mathrm{ion}}+V^{\mathrm H}+\Sigma^{\mathrm{QSGW}}|n\bk\rangle$ over the whole QP window, with $T+V^{\mathrm{ion}}$ from `kin_ion.h5`, $V^{\mathrm H}$ from the orbitals and $\Sigma^{\mathrm{QSGW}}$ the Hermitized $\Sigma^{xc}$ at $E_{m\bk}$ and $E_{n\bk}$, and diagonalizes it into `qp_wfn_rotations.h5`. The BerkeleyGW-format files hold diagonal quantities: `eqp0.dat` is $E^{(0)}_{n\bk}=\mathrm{Re}\,\langle n\bk|T+V^{\mathrm{ion}}+V^{\mathrm H}+\Sigma^{xc}(E_{n\bk})|n\bk\rangle$ and `eqp1.dat` is $E_{n\bk}+Z_{n\bk}(E^{(0)}_{n\bk}-E_{n\bk})$, with $Z_{n\bk}$ from the exact derivative of the on-shell quadrature ([GW theory §4.1](../drivers/gw/theory.md#qp-os)). Self-consistency is QSGW ([`qp_solver`](../drivers/gw/keywords.md#qp_solver) `= self_consistent`), which rotates the orbitals; there is no eigenvalue-only GW.

### k-points without kgrid.x {: #kpoints }

BerkeleyGW builds the full zone from the WFN's k list with the rotation matrices of the header alone; its symmetry record carries no time-reversal flag. Its manual therefore has the NSCF list written by `kgrid.x` without time reversal, or a time-reversal-reduced WFN unfolded afterwards by `wfn_time_reversal.x`, and its `pw2bgw.x` for QE 7.2 allows magnetization only with no symmetries. LORRAX unfolds with every header operation and its composition with time reversal: all of them when time reversal holds, and on a magnet those QE marks `t_rev = 1` ([Symmetry §1.1](../theory/symmetry.md#sym-used)). The NSCF takes `K_POINTS automatic` and `kgrid.x` is not needed ([Inputs from DFT](inputs-from-dft.md#kgrid)). A `WFN.h5` from a `kgrid.x` list is read as well, so a comparison run that gives one file to both codes uses the list BerkeleyGW can unfold.

## Conventions that move numbers {: #conventions }

Each row is a place where the two codes, given one `WFN.h5`, compute different objects by default.

| Convention | BerkeleyGW | LORRAX | To compute the same object |
|---|---|---|---|
| Mini-BZ average of $v(\bq+\bG)$ | `cell_average_cutoff` on $\lvert\bq+\bG\rvert^2$. Unset, it averages every element and rescales the wings on an untruncated semiconductor run, and only $\bq+\bG=0$ otherwise. | `mc_average_vcoul_body = true`: at each $\bq\neq0$ the head-slot element by its average, no wing rescaling; bulk only. | `cell_average_cutoff 1.0d-12` with `mc_average_vcoul_body = false`. |
| Coulomb cutoffs | `bare_coulomb_cutoff` for $\Sigma^x$, `epsilon_cutoff` for $W$. | One $V_\bq$ on `bare_coulomb_cutoff` in $\Sigma^x$ and in $W$. | Equal `bare_coulomb_cutoff`; converge `epsilon_cutoff` and $N_\mu$ each. |
| $\bq\to0$ head | $\varepsilon^{-1}_{00}$ at the shifted $\bq_0$. | $S^{\mathrm{eff}}_{ab}(z)$ from `dipole.h5`, averaged over the Γ cell. | `vhead` = row 1 of the sigma-side `vcoul`; `whead_0freq` = `vhead` × $\varepsilon^{-1}_{00}(\bq_0,0)$; `whead_imfreq` for GN. Values in Ry bohr³. |
| Coulomb hole | Exact static CH by closure on COHSEX (`exact_static_ch 1`, its default there). | Partial sum over `number_bands_sigma`, on every treatment. | `exact_static_ch 0`; compare the primed `CH'`, `Sig'` columns. |
| Band sum of $\Sigma^c$ | Truncated at `number_bands`. | Extrapolated past `number_bands_sigma`. | `use_band_extrapolation = false`, or the `*_raw` columns of `sigma_diag.dat`. |
| Exchange–correlation potential | $E_{n\bk}+\Sigma-V^{xc}$ with `vxc.dat`. | $V^{xc}$ never formed: $T+V^{\mathrm{ion}}$ from `kin_ion.h5`, $V^{\mathrm H}$ from the orbitals. | Align each code to its own VBM before comparing energies. |
| $Z$ in `eqp1.dat` | Finite difference, forward at 1.0 eV by default (plasmon pole). | Exact derivative of the on-shell quadrature. | Compare `eqp0.dat` first; `eqp1.dat` also differs by the curvature of $\Sigma^c$. |
| $\bk$ list | The `sigma.inp` list. | The WFN wedge, in WFN order. | Join by crystal coordinate modulo a reciprocal lattice vector. |

The imposed-head keys are on [The q → 0 head §6](../theory/q0-head.md#bgw-impose); the extrapolation model is on [Band extrapolation](../theory/band-extrapolation.md#trunc-compare).

### Comparing outputs {: #outputs }

`sigma_diag.dat` has one block per wedge point, headed `k-point K:` (0-based position) and a `# kcrys` line. **Its band index `n` is 0-based**: `n=18` is BerkeleyGW band 19. All values are eV.

| `sigma_diag.dat` | `sigma_hp.log` |
|---|---|
| `sigX` | `X` |
| `sigC` | `SX-X` + `CH'` (plasmon pole); `Re Cor` (full frequency) |
| `sigXC` | `Sig'` |
| `sigSX` (COHSEX) | `X` + `SX-X` |
| `sigCOH` (COHSEX) | `CH'` |
| `sigTOT` (COHSEX) | `Sig'` |
| `Eo` | `Emf` |
| `Z` | `Znk` |
| `VH` | none: BerkeleyGW subtracts `Vxc` instead |

## Translating a BerkeleyGW run {: #translate }

The run below is a full-frequency G₀W₀ of Si with spin–orbit coupling (8 occupied spinor bands) on a 4×4×4 grid, with $\Sigma$ for bands 1–24.

```text
# epsilon.inp
epsilon_cutoff               25.0
number_bands                 100
frequency_dependence         2
frequency_dependence_method  2
use_wfn_hdf5
begin qpoints
  0.000000000  0.000000000  0.001000000  1.0  1
  ...
end
```

```text
# sigma.inp
bare_coulomb_cutoff          25.0
screened_coulomb_cutoff      25.0
number_bands                 100
band_index_min               1
band_index_max               24
frequency_dependence         2
frequency_dependence_method  2
cell_average_cutoff          1.0d-12
use_wfn_hdf5
begin kpoints
  ...
end
```

Both collapse into one deck, `gw.in`:

```ini
[cohsex]
wfn_file               = WFN.h5
centroids_file         = centroids_frac_1100.txt   # the name kmeans_cli prints
sys_dim                = 3                         # no truncation
number_bands           = 100                       # both number_bands
nval                   = 8
ncond                  = 16                        # bands 1-24 = 8 occupied + 16
compute_mode           = tangential                # frequency_dependence 2
qp_solver              = one_shot_dft
bare_coulomb_cutoff    = 25.0
mc_average_vcoul_body  = false                     # cell_average_cutoff 1.0d-12
use_band_extrapolation = false                     # BerkeleyGW truncates
```

- `epsilon_cutoff`, `screened_coulomb_cutoff`, the frequency method and both $\bk$ and $\bq$ lists have no line: $N_\mu$ replaces the cutoffs, the treatment the method, and the WFN grid the lists.
- The last two lines exist only to match BerkeleyGW. A production deck omits them.
- `WFN.h5` holds at least one band above `number_bands` (here at least 101); neither band sum may end inside a Kramers pair.

With the launch prefix `$RUN` of the [Quickstart](quickstart.md#launch):

```bash
$RUN centroid.kmeans_cli 1100 --seed 42 -i gw.in   # replaces epsilon_cutoff
$RUN psp.get_dipole_mtxels -i gw.in              # replaces WFNq and q0
$RUN gw.kin_ion_io -i gw.in                      # replaces vxc.dat
$RUN gw.gw_jax -i gw.in                          # replaces epsilon.x + sigma.x
```

Compare `eqp0.dat` and `eqp1.dat` row by row after joining $\bk$ by coordinate and aligning each code to its own VBM, or `sigma_diag.dat` against `sigma_hp.log` by the [column map](#outputs). Converge $N_\mu$ to the target accuracy before attributing a difference to physics ([ISDF accuracy](../theory/isdf.md#isdf-accuracy)).

The BSE step of a `kernel.inp` with `number_val_bands 4` and `number_cond_bands 4`, and an `absorption.inp` with `haydock`, `use_momentum`, `eqp_corrections`, `number_iterations 200` and `energy_resolution 0.1`, is:

```bash
$RUN psp.get_dipole_mtxels -i gw.in --skip-vnl --out dipole_p_only.h5
$RUN bse.absorption_haydock -i gw.in
```

with these lines in `gw.in`, absorption.inp's own:

```ini
number_val_bands_fine 4
number_cond_bands_fine 4
use_momentum
dipole_file dipole_p_only.h5
eqp_corrections eqp1.dat
number_iterations 200
energy_resolution 0.1
```

The BSE inherits the GW run's Coulomb and head conventions through the restart bundle. To compare kernels, give both codes the same `eqp1.dat`: a BerkeleyGW file qualifies when `sigma.x` ran on the WFN's $\bk$ list in WFN order, and any other order refuses. Compare $\varepsilon_2(\omega)$, not sums of $|d|^2$.

## Measured agreement {: #agreement }

One `WFN.h5` in both codes, with the keys of [Conventions](#conventions) matched. Measured on the ω grid with a ±0.5 eV $Z$ stencil, before on-shell $\Sigma^c$ became the default (2026-10-16).

| Run | Quantity | LORRAX − BerkeleyGW |
|---|---|---|
| Full-frequency G₀W₀, Si with SOC, 4×4×4, 100 bands in both sums, 1100 centroids. BerkeleyGW: contour deformation, `epsilon_cutoff 25`. | indirect gap (BerkeleyGW 1.0798 eV) | +0.1 meV |
| | direct gap (3.0706 eV) | +1.5 meV |
| | `eqp1`, 12 states within ±1 eV of midgap, VBM-aligned | std 0.6 meV, max 1.7 meV |
| | `eqp1`, 142 states within ±10 eV | std 6.4 meV, max 22.8 meV (`eqp0`: 2.5, 8.7 meV) |
| Static COHSEX, Si 4×4×4, 60 bands, 960 centroids. BerkeleyGW: `exact_static_ch 0`; its head imposed with `vhead`, `whead_0freq`. | screened exchange against `X + (SX-X)` | 0.10 meV mean absolute, 0.27 meV max |
| | Coulomb hole against `CH'` | 0.35, 1.26 meV |
| | total against `Sig'` | 0.34, 1.07 meV |

Both rows ran with `mc_average_vcoul_body = false` against `cell_average_cutoff 1.0d-12`, and the full-frequency row with `use_band_extrapolation = false`. The two LORRAX defaults move the numbers most: band extrapolation lowers every state by about 155 meV and opens the indirect gap to 1.1256 eV (+45.8 meV); `mc_average_vcoul_body = true` moves $\Sigma^x$ by 136 meV (mean absolute) on the COHSEX deck. The full-frequency LORRAX run took 55 s on four A100 GPUs. No metal and no slab has a matched comparison.
