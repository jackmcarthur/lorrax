# 5.4 Symmetry and orbit closure, briefly

Crystal symmetry enters the ISDF machinery in two user-visible ways. The full
formalism — the unfolding equations for $\psi$, $\zeta$, and $V_q$, time-reversal
augmentation, and the precise ledger of which pipeline stages are symmetry-reduced —
lives in Appendix A. What a user must know:

**You get slightly more centroids than you asked for.** For the symmetry machinery to
act on the ISDF basis at all, the point set $\{\mathbf{r}_\mu\}$ must map onto itself
under every space-group operation (plus time reversal where applicable): it must be a
union of **closed orbits**. The centroid generator therefore takes the k-means result
and closes each orbit, snapping images onto the FFT grid, so a request for e.g. 600
points may return 640-ish. This is normal, and the small surplus is pure gain — the
extra points are symmetry images carrying real fitting information. (Generating
centroids with orbit closure disabled is possible but forfeits everything below.)

**Fits run on the irreducible wedge.** With a closed centroid set, the fitting
matrices at symmetry-equivalent momentum transfers are related exactly, so LORRAX
factorizes $C_q$ and solves for $\zeta_q$ **only for $\mathbf{q}$ in the irreducible
Brillouin zone**, then recovers the full zone by unfolding ($V_q$ likewise, and the
bare exchange $\Sigma_x$ rides the same cascade). For a typical hexagonal cell this is
a ~6–12× reduction of the most expensive stages. The cascade activates automatically
when the centroid set is orbit-closed; the log states plainly whether it engaged and,
if not, which orbit failed closure.

Not everything is reduced: in particular the quasi-density accumulation
(the $P_\mathbf{k}$ sums of §5.3) runs over the full k-lattice — reduction there is
possible in principle but not implemented. Appendix A carries the honest ledger, kept
current against the code.
