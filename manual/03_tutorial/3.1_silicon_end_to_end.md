# 3.1 Silicon, end to end

Bulk silicon from QE input to quasiparticle energies; minutes on one GPU.

QE runs noncollinear with spin-orbit coupling (the code is spinor-only, §5.2), with
fully-relativistic ONCV pseudopotentials. SCF on a converged grid (8×8×8), then NSCF
on the unshifted GW grid (4×4×4 here) with the empty states, `conv_thr` tight
(1e-10):

```fortran
&system                          ! both runs
   ibrav = 2, celldm(1) = 10.26
   nat = 2, ntyp = 1
   ecutwfc = 60.0
   noncolin = .true.
   lspinorb = .true.
   no_t_rev = .true.
   nbnd = 80                     ! NSCF: valence + empties
/
```

Export with `pw2bgw.x` (wavefunctions plus the $\langle V_{xc}\rangle$ and
kinetic+ionic matrix elements), then convert to HDF5:

```fortran
&input_pw2bgw
   prefix = 'Si'
   real_or_complex = 2
   wfng_flag = .true.,  wfng_file = 'WFN'
   wfng_kgrid = .true., wfng_nk1 = 4, wfng_nk2 = 4, wfng_nk3 = 4
   vxc_flag = .true.,   vxc_file = 'vxc.dat'
   kih_flag = .true.,   kih_file = 'kih.dat'
/
```

```bash
pw2bgw.x -in pw2bgw.in > pw2bgw.out
wfn2hdf.x BIN WFN WFN.h5
```

Preprocessing, three artifacts (`lxpre cohsex.in 400` on Perlmutter):

```bash
python -m centroid.kmeans_cli 400 --seed 42     # centroids_frac_400.txt  (§5.1)
python -m psp.get_dipole_mtxels -i cohsex.in    # dipole.h5               (§6.4)
python -m gw.kin_ion_io -i cohsex.in            # kin_ion.h5              (§9.1)
```

400 centroids is ~10 per band in the fitting window (§5.5); the returned set is
slightly larger by orbit closure (§5.4). The input file:

```ini
[cohsex]
wfn_file        = WFN.h5
centroids_file  = centroids_frac_400.txt
nval  = 8            # spinor valence bands of Si
ncond = 12           # bands to correct
nband = 80           # summation bands (= NSCF nbnd)
sys_dim = 3          # bulk, no truncation (§6.1)
qp_solver = one_shot_dft
output_file = eqp0.dat
```

```bash
python -m gw.gw_jax -i cohsex.in
```

The log follows Chapters 5–7 in order: centroid load, ζ fit, $V_q$, screening, Σ,
quasiparticle solve. `eqp0.dat`/`eqp1.dat` (identical in static mode, §4.5) list
k-point, band, $\varepsilon^{DFT}$, $\varepsilon^{QP}$ in eV.
