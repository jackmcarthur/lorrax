# 3.1 Silicon, end to end

This walkthrough takes bulk silicon from a fresh QE input to quasiparticle energies.
Every command is shown; on a single GPU the LORRAX steps complete in minutes. (If you
have not yet run the bundled fixture of §2.2, do that first — it verifies the install
without any of the DFT machinery below.)

## Step 0 — DFT with Quantum ESPRESSO

LORRAX is spinor-first (§5.2): run QE **noncollinear with spin-orbit coupling**, with
fully-relativistic norm-conserving pseudopotentials (ONCV FR from PseudoDojo are the
standard choice). Two `pw.x` runs — an SCF for the density, then an NSCF on the
uniform GW k-grid with the empty states:

```fortran
&system                          ! both runs
   ibrav = 2, celldm(1) = 10.26
   nat = 2, ntyp = 1
   ecutwfc = 60.0
   noncolin = .true.
   lspinorb = .true.
   no_t_rev = .true.
   nbnd = 80                     ! NSCF: valence (8 spinor bands) + empties
/
```

SCF on a converged grid (e.g. 8×8×8 Monkhorst–Pack); NSCF on the **unshifted GW
grid** — 4×4×4 for this tutorial — with `calculation = 'nscf'` and explicit k-points.
Converge `conv_thr` tightly (1e-10): GW inherits any DFT noise.

## Step 1 — export to the BerkeleyGW format

`pw2bgw.x` writes the wavefunctions plus the two matrix-element files LORRAX needs
for the quasiparticle equation:

```fortran
&input_pw2bgw
   prefix = 'Si'
   real_or_complex = 2
   wfng_flag = .true.,  wfng_file = 'WFN'
   wfng_kgrid = .true., wfng_nk1 = 4, wfng_nk2 = 4, wfng_nk3 = 4
   vxc_flag = .true.,   vxc_file = 'vxc.dat'      ! ⟨V_xc⟩ matrix elements
   kih_flag = .true.,   kih_file = 'kih.dat'      ! kinetic + ionic Hamiltonian
/
```

then convert to HDF5 with BerkeleyGW's `wfn2hdf.x`:

```bash
pw2bgw.x -in pw2bgw.in > pw2bgw.out
wfn2hdf.x BIN WFN WFN.h5
```

## Step 2 — LORRAX preprocessing (three artifacts)

From the run directory containing `WFN.h5` and your `cohsex.in` (step 3):

```bash
python -m centroid.kmeans_cli 400 --seed 42     # → centroids_frac_400.txt   (§5.1)
python -m psp.get_dipole_mtxels -i cohsex.in    # → dipole.h5                (§6.4)
python -m gw.kin_ion_io -i cohsex.in            # → kin_ion.h5               (§9.1)
```

(On Perlmutter: `lxpre cohsex.in 400` runs all three.) The centroid count 400 ≈ 10
points per band in the fitting window; §5.5 is the convergence discussion. Expect the
returned set to be slightly larger — that is orbit closure (§5.4).

## Step 3 — the GW input

`cohsex.in`, minimal static-COHSEX version:

```ini
[cohsex]
wfn_file        = WFN.h5
centroids_file  = centroids_frac_400.txt
nval  = 8            # spinor valence bands of Si
ncond = 12           # bands you want corrected
nband = 80           # summation bands (= NSCF nbnd)
sys_dim = 3          # bulk: no truncation (§6.1)
qp_solver = one_shot_dft
output_file = eqp0.dat
```

## Step 4 — run and read

```bash
python -m gw.gw_jax -i cohsex.in        # workstation
# cluster: srun/lxrun per §2.4
```

The log narrates the pipeline of Chapters 5–7 in order: centroid load → ζ fit
(per-IBZ-q Cholesky) → $V_q$ → screening → Σ → quasiparticle solve. Results land in
`eqp0.dat`/`eqp1.dat` (§4.5 semantics; identical in static mode): columns are k-point,
band, $\varepsilon^{DFT}$, $\varepsilon^{QP}$ in eV. For Si at these settings expect
the familiar ~1.2 eV indirect gap once converged.
