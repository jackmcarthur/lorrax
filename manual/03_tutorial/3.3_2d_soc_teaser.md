# 3.3 A 2D + SOC example: monolayer MoS₂

The changes relative to §3.1, sketched. QE: a slab cell with ~15 Å vacuum,
`assume_isolated = '2D'`; the SOC flags now do real work (the K-valley valence
splitting is ~150 meV). Convergence demands dense k-grids, the regime where the
$O(N_k \log N_k)$ scaling pays: 6×6 → 12×12 costs ~4.4× runtime rather than the
~16× of a quadratic-in-$N_k$ code.

```ini
sys_dim = 2                    # slab truncation, mandatory (§6.1)
nval = 26
ncond = 44
nband = 80
```

plus a denser centroid set (~600 for this window). Preprocessing, commands, and
outputs are as in §3.1/§3.2.

In the output: the printed $\bar v_0$ head average is finite (without `sys_dim = 2`
the gap drifts with vacuum thickness); the two spin-split VBM states at K carry
different self-energy corrections; rerunning at 6×6 and 9×9 shows both the gap
convergence and the §4.3 runtime scaling directly.

second centroid set, §8.2).
