# 3.3 Where LORRAX earns its keep: a 2D + SOC teaser

Silicon is a validation system — any GW code does silicon. The calculations LORRAX
was built for look like monolayer MoS₂: two-dimensional (truncated Coulomb, slowly
converging k-sums) with heavy atoms (spin-orbit splitting comparable to the
quantities of interest). This section sketches the changes relative to §3.1; it is a
teaser, not a full walkthrough.

**QE side.** A slab cell with ~15 Å vacuum; `assume_isolated = '2D'`;
`noncolin`/`lspinorb` as always (now doing real work: the K-valley valence splitting
of MoS₂ is ~150 meV). The GW k-grid is where 2D bites: exciton and self-energy
convergence demand dense grids, and this is precisely the regime where LORRAX's
$O(N_k \log N_k)$ scaling (§4.3) pays — going from 6×6 to 12×12 costs ~4.4× runtime
rather than the ~16× a quadratic-in-$N_k$ code pays.

**LORRAX side**, the deltas from the silicon input:

```ini
sys_dim = 2                    # slab truncation — mandatory (§6.1)
nval = 26                      # spinor valence bands of MoS2
ncond = 44
nband = 80
```

plus a denser centroid set (2D systems localize pair densities in the layer;
~600 points for this window). Everything else — preprocessing, run commands,
outputs — is identical to §3.1/§3.2.

Physics to look for in the output:

- The **truncation working**: the printed $\bar v_0$ head average is finite and
  large; without `sys_dim = 2` the gap would drift with vacuum thickness (§6.1).
- **SOC in the QP structure**: the two spin-split VBM states at K acquire different
  self-energy corrections — resolvable only because the whole pipeline is
  spinor-native (§5.2).
- **k-grid convergence**: rerun at 6×6 and 9×9 and watch the gap converge; the
  runtime ratio between the runs is the §4.3 scaling made tangible.

For a 2D *magnetic* system or the Breit-interaction physics of heavy-element
monolayers, continue to Chapter 8 — the bispinor formalism is the same input file
with `bispinor = true` and a second centroid set (§8.2).
