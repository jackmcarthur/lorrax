# 3.2 The same system, dynamically screened

Static COHSEX is a good scaffold and a rough approximation. Upgrading the §3.1 run to
GN-PPM — full frequency dependence of Σ through a Godby–Needs plasmon-pole model of
W (Ch. 7) — is an input-file change, and the restart machinery reuses everything
expensive (ζ fit, $V_q$) from the COHSEX run if the ISDF settings are unchanged:

```ini
[cohsex]
# ... everything from §3.1, plus:
restart = true
compute_mode = gn_ppm
ppm_omega_p  = 2.0            # imaginary probe frequency for the GN fit (Ry)
ppm_invalid_mode = static_limit   # invalid poles → static-COHSEX term (BGW mode 3)

sigma_omega_min_ev  = -10.0   # frequency window for Σ(ω), relative to E_F
sigma_omega_max_ev  =  10.0
sigma_omega_step_ev =  0.5
sigma_regularization_ev = 0.25   # the broadening η of §4.4

sigma_omega_h5_file = sigma_mnk.h5
```

Run as before. Three things change in the output:

1. **`eqp1.dat` now differs from `eqp0.dat`.** The self-energy is
   frequency-dependent, so the Z-factor linearization (§4.5) is nontrivial. `eqp1` is
   the number to quote for G₀W₀.
2. **`sigma_mnk.h5`** holds the full $\Sigma_{ij\mathbf{k}}(\omega)$ on your ω-grid —
   plot the diagonal elements to *see* the quasiparticle equation being solved: the
   crossing of $\omega - \varepsilon^{DFT} + \langle V_{xc}\rangle$ with
   $\mathrm{Re}\,\langle\Sigma(\omega)\rangle$ is the graphical solution, and its
   slope at the crossing is $1 - 1/Z$.
3. **The log reports the plasmon-pole fit census** — how many $(\mu\nu)$ poles were
   valid and what fraction fell back to the static limit (`ppm_invalid_mode`). A
   healthy semiconductor run has a small invalid fraction; §7.4 explains what
   validity means.

Try changing `qp_solver = one_shot_dft` to `fixed_point` and compare: for silicon the
on-shell solution barely moves (Σ is smooth near the QP energies); the difference
grows in systems with satellite structure.
