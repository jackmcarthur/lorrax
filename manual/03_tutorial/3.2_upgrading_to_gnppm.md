# 3.2 The same system, dynamically screened

GN-PPM (Ch. 7) is an input-file change; with `restart = true` and unchanged ISDF
settings the ζ fit and $V_q$ are reused from the §3.1 run:

```ini
[cohsex]
# ... everything from §3.1, plus:
restart = true
compute_mode = gn_ppm
ppm_omega_p  = 2.0                # imaginary probe frequency (Ry)
ppm_invalid_mode = static_limit   # invalid poles: static-COHSEX term (BGW mode 3)

sigma_omega_min_ev  = -10.0       # Sigma(omega) window, relative to E_F
sigma_omega_max_ev  =  10.0
sigma_omega_step_ev =  0.5
sigma_regularization_ev = 0.25    # broadening (§4.4)

sigma_omega_h5_file = sigma_mnk.h5
```

Changes in the output: 1.) `eqp1.dat` now differs from `eqp0.dat`, since Σ is
frequency-dependent and the Z-factor linearization (§4.5) is nontrivial; quote
`eqp1` for $G_0W_0$. 2.) `sigma_mnk.h5` holds $\Sigma_{ij\mathbf{k}}(\omega)$ on the
ω grid; the crossing of $\omega - \varepsilon^{DFT} + \langle V_{xc}\rangle$ with
$\mathrm{Re}\,\langle\Sigma(\omega)\rangle$ is the graphical QP solution. 3.) the
log prints the plasmon-pole fit census; a small invalid fraction is normal for a
semiconductor (§7.4).

`qp_solver = fixed_point` gives the on-shell solution; for Si it barely differs

screening evaluations and the per-τ Σ kernel (§7.5): seconds at this size.
