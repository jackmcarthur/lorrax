# 11.1 The `cohsex.in` reference

Every key the parser reads, grouped as in `LorraxConfig` (`src/gw/gw_config.py`,
the authority on spelling and defaults; this chapter is regenerated against it).
String values are case-insensitive. Keys with default "derived" are resolved at
startup as listed in the final table.

## Band-path block and htransform prep (§9.3)

`K_POINTS {crystal_b}` (outside `[cohsex]`, QE band syntax: a segment count, then
`kx ky kz npts # label` rows) defines the interpolation path only; the GW k-grid
always comes from `WFN.h5`. The `get_centroids_fi` / `wfn_fi_min` / `wfn_fi_max` /
`kgrid_fi` group gates fine-grid wavefunction recovery for BSE work.

## Derived defaults

`bare_coulomb_cutoff`, `zeta_cutoff`, `ecutrho`: unset → the wavefunction cutoff,
ceilinged by the density cutoff (§6.3). `memory_per_device_gb` 0 → detected from
the device. `compute_mode`/`qp_solver` auto → resolved from the legacy flags (both
default to `cohsex` + `one_shot_dft` on a clean input). `slab_io`,
`distributed_*`, `sigma_omega_accumulation` auto → best available backend for the
platform and mesh.
