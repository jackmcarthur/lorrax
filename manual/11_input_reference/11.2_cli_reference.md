# 11.2 Command-line tools

Preprocessing (§10.1):

| Command | Output | Key options |
|---|---|---|
| `python -m centroid.kmeans_cli <N>` | `centroids_frac_<N>.txt` | `--seed`, `--density-mode current` (bispinor transverse set), `--no-orbit` (disables closure and the IBZ cascade), `--oversample` |
| `python -m psp.get_dipole_mtxels -i cohsex.in` | `dipole.h5` | reads the band window from the input |
| `python -m gw.kin_ion_io -i cohsex.in` | `kin_ion.h5` | chunked variant for large systems |

GW driver: `python -m gw.gw_jax -i cohsex.in` (console scripts `gw_jax`,
`lorrax-gw`). All physics options live in the input file (§11.1).

BSE driver: `python -m bse.bse_jax` (§9.2). Selected flags; `--help` is complete:

| Flag group | Purpose |
|---|---|
| `--tda` / `--rpa` / `--bse` | kernel level: Tamm–Dancoff, RPA, full |
| `--n-val`, `--n-cond`, `--n-occ`, `--eqp` | transition window and QP energies |
| `--px`, `--py` | processor mesh |
| `--lanczos`, `--n-reorth` | Lanczos eigenpairs (`-1` = full reorthogonalization, required for spinor BSE) |
| `--feast-*` | contour-window interior eigensolver (windows, quadrature, Ritz counts) |
| `--kpm-*` | excitonic DOS (moments, random vectors, energy range, plot) |
| `--gmres-*` | shifted solves for exact $W_c(\omega)$ |
| `--matvec-kind` | `simple` (default) or `ring` (memory-tight meshes) |

Band structures: `python -m bandstructure.htransform` (§9.3) with `--eqp-file`,
`--a-band`, `--plot`; the k-path comes from the `K_POINTS {crystal_b}` block.
Utilities: `postprocess.rotate_wfn_to_qp` (QP-rotated wavefunctions),
`psp.orbital_magnetization` (modern-theory orbital magnetization from `WFN.h5`).
