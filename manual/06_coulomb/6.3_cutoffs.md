# 6.3 Cutoffs: pair densities carry twice the wavevector

A wavefunction cutoff $E_{\text{cut}}$ bounds coefficients at
$G_{\max} = \sqrt{E_{\text{cut}}}$, but GW integrates pair densities, which are
convolutions

$$
\big[\psi^*_m \psi_n\big](\mathbf{G}) \;=\; \sum_{\mathbf{G}'}
c_m^*(\mathbf{G}'-\mathbf{G})\, c_n(\mathbf{G}')
$$

carrying wavevectors up to $2G_{\max}$: an energy cutoff of $4E_{\text{cut}}$, the
same statement as `ecutrho` $= 4\times$ `ecutwfc` in DFT. Because ζ is fitted in
real space and transformed as a density, the Coulomb matrix elements of §5.3 can be
integrated over G-spheres up to `ecutrho`. Two keys control this:

- `bare_coulomb_cutoff` (Ry): the G-sphere for Coulomb matrix elements. Default
  $E_{\text{cut}}$, matching BerkeleyGW's `screened_coulomb_cutoff` default;
  raisable to `ecutrho`, beyond which the code refuses.
- `zeta_cutoff` (Ry): the G-sphere on which ζ is stored. Default $E_{\text{cut}}$,
  ceiling `ecutrho`, constrained to `zeta_cutoff` ≥ `bare_coulomb_cutoff` since
  $V_q$ reads $\tilde\zeta(\mathbf{q}+\mathbf{G})$ on its full sphere.

> **BGW correspondence.** The plane-wave pipeline builds χ and Σ from wavefunction
> coefficients directly, so its dielectric cutoff is capped at $E_{\text{cut}}$;
> the region $E_{\text{cut}} < |\mathbf{q}+\mathbf{G}|^2 \le 4E_{\text{cut}}$ is
> one input key away in LORRAX and structurally inaccessible there. Defaults match;
> a raised `bare_coulomb_cutoff` must be pinned back to the BGW value in parity
> studies.

Raising `bare_coulomb_cutoff` toward `ecutrho` is a cheap convergence dial for
absolute exchange energies: the kernel decays as $1/G^2$ and the FFTs are already
paid for.
