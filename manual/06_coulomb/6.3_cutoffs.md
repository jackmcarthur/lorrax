# 6.3 Cutoffs: pair densities carry twice the wavevector

A plane-wave DFT calculation with energy cutoff $E_{\text{cut}}$ contains
wavefunction components up to $G_{\max} = \sqrt{E_{\text{cut}}}$ (Ry units). But GW
never integrates bare wavefunctions against the Coulomb kernel — it integrates
**pair densities**, and a product of two wavefunctions is a convolution in
reciprocal space:

$$
\big[\psi^*_m \psi_n\big](\mathbf{G}) \;=\; \sum_{\mathbf{G}'}
c_m^*(\mathbf{G}'-\mathbf{G})\, c_n(\mathbf{G}'),
$$

which carries wavevectors up to $2G_{\max}$ — an energy cutoff of
$(2G_{\max})^2 = 4\,E_{\text{cut}}$. This is the same statement as the familiar DFT
rule that the charge density needs `ecutrho` $= 4\times$ `ecutwfc`: densities are
products, and products have twice the bandwidth.

**LORRAX can resolve the full pair bandwidth.** The ISDF vectors
$\zeta_{q,\mu}$ are fitted in real space on the FFT grid and transformed *as
densities*, so the Coulomb matrix elements of §5.3 can be integrated over G-spheres
all the way up to $4E_{\text{cut}}$ — the DFT density cutoff (`ecutrho`), the largest
sphere the FFT box can represent. The controlling inputs:

- **`bare_coulomb_cutoff`** (Ry) — the G-sphere for Coulomb matrix elements.
  **Default: the wavefunction cutoff $E_{\text{cut}}$** (deliberately matching
  BerkeleyGW's `screened_coulomb_cutoff` default). Raisable to anything up to
  `ecutrho` $= 4E_{\text{cut}}$; the code refuses values beyond what the FFT grid
  represents.
- **`zeta_cutoff`** (Ry) — the G-sphere on which $\zeta$ itself is stored (the
  disk-resident ζ store). Also defaults to $E_{\text{cut}}$, also raisable to
  `ecutrho`, and constrained to `zeta_cutoff` $\ge$ `bare_coulomb_cutoff` — the
  $V_q$ kernel reads $\tilde\zeta(\mathbf{q}+\mathbf{G})$ at every $\mathbf{G}$
  inside its sphere, so ζ must be stored at least as wide.

> **BGW correspondence.** BerkeleyGW's G-space pipeline builds $\chi$ and $\Sigma$
> from wavefunction coefficients directly, so its dielectric cutoff is *capped at the
> wavefunction cutoff* $E_{\text{cut}}$ — the region
> $E_{\text{cut}} < |{\bf q+G}|^2 \le 4E_{\text{cut}}$ is structurally inaccessible
> there, while in LORRAX it is one input key away. At *defaults* the two codes match
> ($E_{\text{cut}}$ on both sides); a LORRAX run with a raised `bare_coulomb_cutoff`
> is exploring physics a matched BGW run cannot, so parity studies must pin the key
> to the BGW value explicitly.

Practical guidance: the default is the BGW-comparable choice; raising
`bare_coulomb_cutoff` toward `ecutrho` is a cheap convergence dial for absolute
exchange energies (the kernel decays as $1/G^2$, and the FFTs are already paid for)
