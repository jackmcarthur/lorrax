# 6.1 The kernel and its truncation

Chapters 4–5 used the Coulomb interaction abstractly as $v_q(\mathbf{G})$. Concretely,
in the plane-wave representation (BerkeleyGW conventions; Rydberg units, where the
untruncated 3D kernel reads $8\pi/|\mathbf{q}+\mathbf{G}|^2$):

$$
v_q(\mathbf{G}) \;=\; \frac{8\pi}{|\mathbf{q}+\mathbf{G}|^2}\;
T_{\text{cell}}(\mathbf{q}+\mathbf{G}),
$$

where $T_{\text{cell}}$ is a geometry-dependent **truncation factor** selected by the
`sys_dim` input:

- **`sys_dim = 3`** (bulk): $T = 1$. The bare periodic kernel.
- **`sys_dim = 2`** (slab): cell-slab truncation. Interactions are cut at half the
  vertical cell height, $T(\mathbf{q}+\mathbf{G}) = 1 -
  e^{-|\mathbf{q}_\parallel+\mathbf{G}_\parallel| L_z/2}\cos(G_z L_z/2)$, so periodic
  images along $z$ do not screen each other. Required for any 2D material; without it,
  gaps and exciton binding depend artificially on vacuum thickness.
- **`sys_dim = 0`** (box): box truncation for isolated systems (molecules); the
  interaction is confined to the Wigner–Seitz box.

Truncation is not a small correction. In a 2D material the long-wavelength dielectric
function behaves qualitatively differently under the truncated kernel
($\epsilon(q)\to 1$ as $q\to 0$ instead of a bulk-like constant), and every
quantity downstream — screening, self-energy, BSE kernel — inherits the choice. Set
`sys_dim` to the physical dimensionality, always; it defaults to 2 for safety in
layered-material work, and a bulk calculation accidentally run truncated is as wrong
as the reverse.

> **BGW correspondence.** `sys_dim = 3/2/0` corresponds to no truncation /
> `cell_slab_truncation` / `cell_box_truncation` in `epsilon.inp`/`sigma.inp`.
> Wire truncation (1D) is not currently implemented in LORRAX.

Because all ISDF Coulomb matrix elements are assembled in reciprocal space
(§5.3), truncation costs nothing: it is a multiplicative factor on the kernel
evaluated per $(\mathbf{q}+\mathbf{G})$, applied identically in the bare-exchange,
screening, and BSE builds. Implementation: `src/gw/coulomb/{bulk_3d,slab_2d,box_0d}.py`
behind one dispatch (`compute_vcoul.py`, `compute_vcoul_0d.py`).

Two features of the $q\to 0$ region need their own treatment: the average of the
diverging kernel over the zone cell around $\mathbf{q}=0$ (§6.2), and the interplay
of that divergence with the vanishing polarizability (§6.4 → Appendix B).
