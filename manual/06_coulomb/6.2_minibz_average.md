# 6.2 The mini-BZ average

Each grid point $\mathbf{q}$ stands in for a cell of volume $\Omega_{BZ}/N_q$. At
$\mathbf{q}=0$, $\mathbf{G}=0$ the kernel diverges as $1/q^2$ and the midpoint
value is replaced by the cell average

$$
\bar v_0 \;=\; \frac{N_q}{\Omega_{BZ}} \int_{\text{miniBZ}(0)} d^3q'\; v_{q'}(0),
$$

finite in every dimensionality ($\int d^3q/q^2 \sim q$; in 2D the truncated kernel
diverges only as $1/q$). LORRAX evaluates it by Monte-Carlo integration over the
Voronoi cell of $\mathbf{q}=0$ (`compute_q0_averages`, `gw/vcoul.py`), the same
prescription as BerkeleyGW. Related keys: `mc_average_vcoul_body` extends the cell
average to nonzero $\mathbf{q}$ (on by default; applied only for `sys_dim = 3`);
`use_bgw_vcoul` / `bgw_vcoul_file` import BerkeleyGW's `vcoul` wholesale for parity
studies (App. E); `vhead` overrides $\bar v_0$ directly.

This handles the bare kernel. The screened head at $\mathbf{q}\to0$ additionally
requires the $q^2$ coefficient of the polarizability: §6.4, Appendix B.
