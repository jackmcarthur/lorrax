# 6.2 The mini-BZ average

A $k$-grid calculation replaces continuous Brillouin-zone integrals with a discrete
sum: each grid point $\mathbf{q}$ stands in for a small surrounding cell (the
"mini-BZ", volume $\Omega_{BZ}/N_q$). For smooth integrands the midpoint value is
fine. The Coulomb kernel is not smooth — at $\mathbf{q}\to 0$, $\mathbf{G}=0$ it
diverges as $1/q^2$ — and the midpoint prescription would simply be infinite, while
*dropping* the point underestimates every exchange energy by a finite, grid-dependent
amount.

The correct replacement at the divergent point is the **cell average** of the kernel,

$$
\bar v_0 \;=\; \frac{N_q}{\Omega_{BZ}} \int_{\text{miniBZ}(0)} d^3q'\; v_{q'}(0),
$$

which is finite in every dimensionality ($\int d^3q/q^2 \sim q$; in 2D the truncated
kernel diverges only as $1/q$ and $\int d^2q/q \sim q$). LORRAX evaluates it by
**Monte-Carlo integration over the Voronoi cell** of $\mathbf{q}=0$
(`compute_q0_averages` in `gw/vcoul.py`), the same prescription BerkeleyGW uses, so
matched comparisons agree point by point.

Options a user may meet:

- **`mc_average_vcoul_body`** — extend the MC cell average to the *nonzero*
  $\mathbf{q}$ points as well ("body" averaging). The kernel is smooth there, and the
  average differs from the midpoint value at the sub-percent level that matters
  mainly in finite-size extrapolations. **On by default**, and applied only in bulk
  (`sys_dim = 3`) calculations — for truncated geometries it is a silent no-op.
- **`use_bgw_vcoul` / `bgw_vcoul_file`** — import BerkeleyGW's `vcoul` values wholesale
  instead of computing them, eliminating this entire section as a source of
  discrepancy in parity studies (Appendix E).
- **`vhead`** — override the averaged head value $\bar v_0$ explicitly (expert /
  debugging use).

The mini-BZ average handles the *bare* kernel's divergence. What it cannot decide is
how the **screened** interaction behaves at $\mathbf{q}\to 0$ — that requires knowing
how the polarizability vanishes, which involves transition dipoles and is deferred to
§6.4 and Appendix B.
