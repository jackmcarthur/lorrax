# 7.2 The minimax toolbox

The production minimax service owns the sign-definite screening kernels.
For $x \in [x_{min}, x_{max}]$, $x > 0$,

$$
\frac{1}{x} \approx \sum_{l=1}^{N} w_l\, e^{-t_l x}.
$$

Nodes and weights minimize worst-case error over the interval, with rank
growing logarithmically in $R=x_{max}/x_{min}$. The shipped static catalog
covers $R\le10^5$; selection rounds range upward and tolerance downward and
returns the artifact provenance.

The imaginary-frequency GN probe has the distinct target

$$
\frac{x}{x^2+\omega_p^2}
\approx \sum_l \alpha_l e^{-\tau_l x},
$$

with an optional same-support sine kernel for ordered particle-hole
orientations. It is separately certified because a rule for $1/x$ does not
certify this target.

The old HGL sine target is retired: it had no production caller and did not
preserve the configured Lorentzian observable. Dynamic GN/HL-PPM and MPA $\Sigma$
instead use the uniform fixed-eta denominator-box service described in §7.5.
That service shares the existing time-domain executor but is not a minimax
catalog family or a fallback from one.

Runtime nonlinear fitting is only an explicit, announced escape hatch for
supported sign-definite families. A missing HGL request refuses as an unknown
family/target; it cannot silently select another rule.
