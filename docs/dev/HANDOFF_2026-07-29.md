min(n_val, nb-n_val) = 26, so centroids were chosen on a (0,26)x(0,52) window

independent pair densities, so achievable ISDF rank is MATHEMATICALLY CAPPED at

=> WITHDRAWN: every physics number from a big-mu b1024 rung (rung 6's 1.4296 eV
   included). Capacity/memory results from those runs are UNAFFECTED.
=> A rank-shortfall HARD REFUSAL now gates centroid acceptance.
