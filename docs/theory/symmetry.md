# Symmetry

LORRAX keeps wavefunctions only at the k rows stored in the WFN file, the
*parents*. Every full-grid object (ψ at another k, the Green's function
\(G_{\mathbf k}\), the interpolation vectors \(\zeta_{\mathbf q}\), the
interactions \(V_{\mathbf q}\) and \(W_{\mathbf q}\)) is obtained from a
parent by one space-group action in the ISDF centroid basis. This page
derives that action and states where it may replace a computation. The
tables that realize it, with their builders, shapes and refusals, are in the
[symmetry register](../architecture/symmetry_register.md); the calling API is
on the [`symmetry_maps` service page](../services/symmetry_maps.md).

## 1. Operations

For each spatial operation \(s=0,\dots,n_t-1\) a WFN file stores an integer
matrix \(M_s\) (`mtrx`) and a translation \(\mathbf t_s\) (`tnp`), both in
crystal coordinates. With \(\boldsymbol\tau_s=\mathbf t_s/2\pi\) the Seitz
operation is \(g_s=\{R_s|\boldsymbol\tau_s\}\) with \(R_s=M_s^{-1}\):

| object | action (column vectors) |
|---|---|
| position | \(\mathbf r\mapsto R_s\mathbf r+\boldsymbol\tau_s\) |
| position, pull-back | \(g_s^{-1}\mathbf r=M_s(\mathbf r-\boldsymbol\tau_s)\) |
| \(\mathbf k\), \(\mathbf q\), \(\mathbf G\) | \(\mathbf k\mapsto S_s\mathbf k,\quad S_s=M_s^{\mathsf T}\) |

Products are \(\{R_a|\boldsymbol\tau_a\}\{R_b|\boldsymbol\tau_b\}
=\{R_aR_b|R_a\boldsymbol\tau_b+\boldsymbol\tau_a\}\) modulo a lattice vector,
so \(M_{ab}=M_bM_a\). Reciprocal phases consume the raw \(\mathbf t_s\);
real-space maps use \(\boldsymbol\tau_s\). At the QE boundary the XML
`rotation` text, reshaped row-major with no transpose, equals \(M_s\), and QE's
translation becomes \(\mathbf t_s=2\pi M_s^{-1}\boldsymbol\tau^{\rm QE}_s\)
modulo \(2\pi\).

**Antiunitary rows.** `WFN.h5` does not record which operations QE composed
with time reversal, so each operation has two candidate rows: \(s\), the
unitary \(g_s\), and \(n_t+s\), the antiunitary \(\Theta g_s\), whose
reciprocal matrix is \(S_{n_t+s}=-S_s\). \(\Theta=i\sigma_yK\) on
two-component spinors and \(\Theta=K\) on scalars. Θ leaves positions fixed,
so both rows share the real-space action of \(g_s\).

Which rows may be used is measured. Global time reversal is decided by
comparing occupied two-component DFT subspaces at partner k, never with a
state generated by an antiunitary row. A QE `data-file-schema.xml` that
authenticates the same WFN types each operation individually, so a magnetic
space group keeps its antiunitary operations when global time reversal is
broken. Without the schema every stored operation is taken as unitary,
antiunitary rows come only from a measured global time reversal, and the run
warns that a magnetic antiunitary operation would be mishandled. The
[service page](../services/symmetry_maps.md#contract) owns the verdict.

## 2. The parent-k domain

Each full-grid point has a parent WFN row \(p\) and an operation row \(s\):

$$
\mathbf k=S_s\bar{\mathbf k}_p+\mathbf g_0,\qquad \mathbf g_0\in\mathbb Z^3 .
$$

Parents are the WFN rows as written: no rotation, no gauge fixing, and no
choice of one representative per star. A WFN may store two k of one orbit;
the selection rule then gives one of them no children, and that row is never
read. q parents are one member per orbit of the unshifted mesh. The
[register](../architecture/symmetry_register.md#2-k-and-q-maps) states both
selection rules.

A quantity that is constant on a star, such as an energy or an occupation,
may be read from any member. A wavefunction may not. The full-grid row that
coincides with a stored k can carry a nonidentity or antiunitary operation
from another parent, so ψ is always taken from the WFN row itself.

**The trivial view.** Centroid-basis transport (§3) needs the centroid set to
be closed under every operation it uses. When the set is not orbit-closed,
the run restricts the computational group to the identity
(`SymMaps.trivial_view`). Every grid point is then its own parent
(\(n_{\rm parent}=N_k\)), each realized once from its WFN row by the
plane-wave action of §3, and every q is computed. The view uses no
antiunitary row and reports no time reversal, so consumers that branch on
time reversal take their general, time-reversal-broken form; the loader's
measured verdict is untouched, and file outputs still reduce through the
WFN's own map. A warning names the centroid file; orbit-closed k-means
centroids restore the reduction.

## 3. Wavefunctions

Let \(\alpha_s\) and \(\mathbf L_s\) be the centroid pull-back and lattice wrap
of operation \(s\):

$$
M_s(\mathbf r_\mu-\boldsymbol\tau_s)=\mathbf r_{\alpha_s(\mu)}+\mathbf L_{s\mu},
\qquad \mathbf L_{s\mu}\in\mathbb Z^3 .
$$

Because \((g\psi)(\mathbf r)=\mathcal U\,\psi(g^{-1}\mathbf r)\) and
\(\psi_{\bar{\mathbf k}}(\mathbf r+\mathbf L)
=e^{2\pi i\bar{\mathbf k}\cdot\mathbf L}\psi_{\bar{\mathbf k}}(\mathbf r)\),
the child sampled at a centroid is

$$
\psi_{\mathbf k,a}(\mathbf r_\mu)=\sum_c\mathcal U_{s,ac}\;
\mathcal T_s\!\left[e^{2\pi i\bar{\mathbf k}\cdot\mathbf L_{s\mu}}\,
\psi_{\bar{\mathbf k},c}(\mathbf r_{\alpha_s(\mu)})\right],
$$

where \(\mathcal T_s\) is complex conjugation on an antiunitary row and the
identity otherwise. The spinor factor is

| representation | unitary row | antiunitary row |
|---|---|---|
| scalar, \(n_s=1\) | \(1\) | \(1\) |
| Pauli, \(n_s=2\) | \(U_s\) | \(i\sigma_y\overline{U_s}\) |
| four-component | \(\operatorname{diag}(U_s,\det R_s\,U_s)\) | \(\operatorname{diag}(i\sigma_y\overline{U_s},\det R_s\,i\sigma_y\overline{U_s})\) |

\(U_s\in SU(2)\) is the spinor image of the proper rotation
\(\det(R_s)R_s\) in Cartesian coordinates. The table holds spatial rows only;
the antiunitary factor is formed where it is used. \(n_s=2\) means
noncollinear, with or without spin–orbit coupling.

Centroids are FFT-grid points and every operation is commensurate with the
grid, so \(\alpha_s\) is an exact permutation of a closed set; the
[register](../architecture/symmetry_register.md#3-centroid-tables) gives the
rounding rule that makes \(\mathbf L\) exact.

In the plane-wave basis the same action is

$$
c_{\mathbf k}(S_s\mathbf G-\mathbf g_0)
=\mathcal U_s\,e^{-i(S_s\mathbf G)\cdot\mathbf t_s}\,c_{\bar{\mathbf k}}(\mathbf G)
$$

on a unitary row, and on an antiunitary row

$$
c_{\mathbf k}(-S_s\mathbf G-\mathbf g_0)
=i\sigma_y\overline{U_s}\,e^{+i(S_s\mathbf G)\cdot\mathbf t_s}\,
\overline{c_{\bar{\mathbf k}}(\mathbf G)} .
$$

Θ has two halves here: the spinor factor and the negation of the G list,
which enters through \(S_{n_t+s}=-S_s\). Applying one without the other
replaces \(\psi(\mathbf r)\) by \(\overline{\psi(-\mathbf r)}\). That error
preserves norms, overlaps and the kinetic energy, and shows up only in
position-dependent terms such as the local and nonlocal pseudopotential. The
coefficients are conjugated before the phase is applied. The plane-wave form
omits the band-independent factor
\(e^{-2\pi i(S_s\bar{\mathbf k})\cdot\boldsymbol\tau_s}\) that the centroid
form contains. That factor is a gauge of \(\psi_{\mathbf k}\) and cancels in
every \(G_{\mathbf k}\) and every same-k band matrix.

## 4. Two-point operators: G, χ, V, W

Let \(X_{\mathbf p}(\mathbf r,\mathbf r')\) satisfy
\(X_{\mathbf p}(\mathbf r+\mathbf L,\mathbf r'+\mathbf L')
=e^{2\pi i\mathbf p\cdot(\mathbf L-\mathbf L')}X_{\mathbf p}(\mathbf r,\mathbf r')\),
with centroid matrix \(X_{\mathbf p}[\mu a,\nu b]\). \(G_{\mathbf k}\) has this
form with \(\mathbf p=\mathbf k\); \(\chi_{\mathbf q}\), \(V_{\mathbf q}\) and
\(W_{\mathbf q}\) have it with \(\mathbf p=\mathbf q\). On a unitary row

$$
X_{S_s\bar{\mathbf p}}[\mu,\nu]
=e^{2\pi i\bar{\mathbf p}\cdot(\mathbf L_{s\mu}-\mathbf L_{s\nu})}\;
\mathcal U_s\,X_{\bar{\mathbf p}}[\alpha_s(\mu),\alpha_s(\nu)]\,\mathcal U_s^\dagger ,
$$

with \(\mathcal U_s\) acting on the spin index of each endpoint. The
translation enters only through \(\alpha_s\) and \(\mathbf L_s\); no separate
phase appears in the centroid basis.

The gather uses \(\alpha_s\) as tabulated. \(\alpha_s^{-1}\) is the table of
\(g_s^{-1}\), and the two agree only when \(g_s^2=1\). An order-3 operation
(\(C_3\), \(S_6\)) is the case that tells them apart. The other direction
error, \(\mathbf r\mapsto M_s\mathbf r+\boldsymbol\tau_s\), is not an element
of a nonsymmorphic group and breaks closure.

**Antiunitary rows.** How Θ acts depends on the operator.

* A static Hermitian operator (\(V_{\mathbf q}\), static \(W_{\mathbf q}\)) is
  conjugated:
  \(X_{-S_s\bar{\mathbf p}}[\mu,\nu]
  =e^{-2\pi i\bar{\mathbf p}\cdot(\mathbf L_{s\mu}-\mathbf L_{s\nu})}\,
  \overline{X_{\bar{\mathbf p}}[\alpha_s(\mu),\alpha_s(\nu)]}\), then
  \(\mathcal U_s\) as above (`trs_rule="conj"`).
* An operator at a fixed complex time or frequency is transposed. With
  \(\psi_{\Theta\mathbf k}=\Theta\psi_{\mathbf k}\),
  $$
  G_{\Theta\mathbf k}(\mathbf r,\mathbf r';z)
  =\Theta\,G_{\mathbf k}(\mathbf r',\mathbf r;z)^{\mathsf T}\,\Theta^{-1}
  $$
  at the same \(z\), because the weight \(e^{-\tau E}\) or \(1/(z-E)\)
  multiplies \(\psi\psi^\dagger\) and is not conjugated. The source tile is
  therefore the transpose \(X^{\mathsf T}_{\bar{\mathbf p}}\) over the
  complete (centroid, spin) endpoint, gathered at
  \((\alpha_s(\mu),\alpha_s(\nu))\) with the phase
  \(e^{-2\pi i\bar{\mathbf p}\cdot(\mathbf L_{s\mu}-\mathbf L_{s\nu})}\)
  (`trs_rule="pair_transpose"`). The Green's function supplies its partner
  \(G^{\mathsf T}_{\bar{\mathbf k}}=\sum_n w_n\,\bar\psi_n\psi_n^{\mathsf T}\),
  built from conjugated faces and unconjugated weights. It equals
  \(\overline{G_{\bar{\mathbf k}}}\) only when the weights are real.
  Conjugating instead would send \(G(t)\) to \(G(-t)\) and flip the sign of
  \(\operatorname{Im}\Sigma\), the lifetime. Multipole and shared-pole
  residues use the same rule; pole positions carry no wrap phase.
* A rectangular operator between two centroid families (the charge–current
  tiles CT and TC) uses each family's own \((\alpha,\mathbf L)\) on each
  endpoint. Under the conjugation rule nothing else changes. Under the
  transpose rule its partner is the reversed tile \(X^{\nu\mu}\), not an
  in-place transpose of \(X^{\mu\nu}\).

**Band matrices.** A band matrix projected on a parent reaches the other
members of its star by row gather. On antiunitary rows a frequency-dependent
operator transposes, \(\Sigma_{\Theta\mathbf k,mn}(z)=\Sigma_{\mathbf k,nm}(z)\),
and an observable conjugates,
\(O_{\Theta\mathbf k,mn}=\overline{O_{\mathbf k,mn}}\). On the diagonal the
two differ by the sign of \(\operatorname{Im}\Sigma\). A polar vector index,
such as the velocity, transforms by the forward Cartesian rotation with an
extra \(-1\) on antiunitary rows, because \(\mathbf v\) is odd under time
reversal. An axial index transforms by \(\det(R)R\).

**Four-current operators.** Charge and current indices transform by
\(\Lambda_s=\operatorname{diag}(1,R_s)\) on a unitary row and
\(\operatorname{diag}(1,-R_s)\) on an antiunitary one: the current is a
polar, time-odd vector. A tile with Lorentz indices is first transported by
the scalar rule above, then mixed by \(\Lambda_s\otimes\Lambda_s\) across
the charge and current sectors. \(\Lambda_s\) is real; conjugation and transposition belong
to the scalar transport. The channels are defined in
[four-current heads and frequency](four-current-head-corrections.md).

## 5. Interpolation vectors and the q axis

\(\zeta\) is stored in G space on the parent q wedge. Under row \(s\) the
child at \(\mathbf q+\mathbf G'=S_s(\bar{\mathbf q}+\mathbf G)\) is

$$
\zeta_{\mathbf q,\mu}(\mathbf G')
=e^{-iS_s(\bar{\mathbf q}+\mathbf G)\cdot\mathbf t_s}\,
e^{-2\pi i\bar{\mathbf q}\cdot\mathbf L_{s\mu}}\,
\zeta_{\bar{\mathbf q},\alpha_s(\mu)}(\mathbf G),
$$

conjugated as a whole on an antiunitary row. The child's \(\mathbf G'=0\)
column in general comes from a nonzero parent \(\mathbf G\), so a head column
is transported from the parent sphere, not from the parent's own
\(\mathbf G=0\) column. Substituting into
\(V_{\mathbf q}=\bar\zeta\,\operatorname{diag}(v_{\mathbf q})\,\zeta^{\mathsf T}\)
cancels the translation phase and gives §4 with \(\mathbf p=\mathbf q\).

**q and −q.** \(V_{-\mathbf q}=\overline{V_{\mathbf q}}\) holds for any mean
field. The pair densities fitted at \(-\mathbf q\) are the conjugates of those
at \(+\mathbf q\) with bra and ket exchanged, and \(v(|\mathbf q+\mathbf G|)\)
is real and even. The relation checks the fit, not time reversal, and it
stays in force on a magnet. When global time reversal holds, the q and −q
children of one parent use the same spatial row, one of them composed with Θ.
Reciprocity then depends on Θ alone, not on two unrelated cosets of the little
group. At a self-negative q (a TRIM point of an even mesh) Θ acts as the
one-element projector \(A\mapsto(A+\bar A)/2\), and the removed anti-Θ part is
reported. When time reversal is broken, q and −q are independent parents and
neither step exists.

**Covariance.** Transport assumes the stored parent tile is invariant under
its own little group. That holds exactly for the continuum operator and
approximately for a finite, possibly ill-conditioned ISDF basis. The residual
is measured at every parent with the unfold's own formula and reported.

## 6. Orbit-packed centroids

On the square \(s\times s\) process mesh every centroid axis is held in one
*orbit-packed* order. Centroids are grouped into orbits under the operations
available on the set. Whole orbits are placed on the \(s\) shards of the axis,
largest first onto the least-loaded shard, and each shard is padded at its tail
to a common size that is a multiple of \(s\). Every \(\alpha_s\) then maps
each shard into itself. On an operator sharded \([\mu_X,\nu_Y]\) the transport
of §4 becomes a gather inside each rank's tile. It has no collective and costs
\(O(N_{\rm child}M^2/P)\) memory traffic per rank for \(M\) centroids on \(P\)
ranks. Pad slots are fixed points of every \(\alpha_s\), have zero wrap and hold
exact zeros. One order serves both mesh axes, which is why the layout needs a
square mesh. In canonical order the same transport needs an all-to-all out and
back on each endpoint axis.

Files keep the canonical centroid order at its logical extent. The conversion
happens only where bytes cross a file. The ζ fit unfolds its pair projectors
the same way, over centroid batches that are unions of whole orbits
([ζ fit by μ-batches](../architecture/zeta_fit_mubatch.md)).

## 7. Where symmetry replaces work

| stage | domain | role of symmetry |
|---|---|---|
| ψ storage and load | \(n_{\rm parent}\) k rows | children are transported, never stored |
| Green's function for Σ | \(n_{\rm parent}\) k rows | GEMM on parents, operator transported to \(N_k\) |
| Green's function in the χ₀ τ chain | \(N_k\) | the two ψ faces are transported, then one GEMM |
| ζ fit, \(V_{\mathbf q}\), Dyson solve, pole fits | parent q wedge | solve on parents, transport to \(N_q\) |
| k/q lattice convolution (χ₀, Σ) | complete grid | none: inputs are transported first, with no time-reversal shortcut |
| Σ band projection | parents | band matrix transported by row gather (§4) |
| density, Hartree field | real-space grid | symmetrized by the FFT-grid pull-back |

The two Green placements trade flops against traffic. Transporting faces costs
\(32N_kN_bn_sM/P\) bytes of transient faces per rank and a GEMM over all
\(N_k\). Transporting the operator costs \(n_{\rm parent}/N_k\) of the GEMM
and a quadratic, local gather.

The savings are in per-k and per-q linear algebra, by \(N_k/n_{\rm parent}\)
and \(N_q/N_q^{\rm irr}\) (Si on a \(4\times4\times4\) mesh with 48 operations:
64 → 8 for both), and in ψ storage. The convolution cost does not change,
because a lattice convolution needs every point of a uniform grid.

The action is refused, never approximated: a missing time-reversal verdict,
incomplete k coverage, a stored k off the file's own grid, a required
operation that does not permute the centroids, a packed map that crosses a
shard, or a non-square mesh stops the run. The
[register](../architecture/symmetry_register.md#8-refusals) lists each with
its fix.

## 8. Test systems

No single crystal exercises the whole convention. A nonsymmorphic group tests
\(\boldsymbol\tau\) and the wraps. An order-3 operation tests \(\alpha\)
against \(\alpha^{-1}\). A two-component system whose map selects antiunitary
rows tests \(i\sigma_yK\) and the transpose rule. Si (Fd-3m, 48 operations)
is nonsymmorphic but contains inversion, so its map selects no antiunitary
row. A result validated only on Si says nothing about time reversal.
